# Requirements

VEXUMセミナー資料の**内容要件だけ**を管理するディレクトリです。

## 正本

- [`vexum-seminar-material-requirements.md`](./vexum-seminar-material-requirements.md) — 全体方針、カリキュラム、テーマ別要件を一元管理する Single Source of Truth

## 管理方針

- テーマごとに別の要件ファイルを増やさない。
- テーマ追加・削除・順序変更・難易度変更は統合要件定義書へ反映する。
- 配色、レイアウト、アニメーション等のデザイン仕様は [`../design/`](../design/) で管理する。
- 旧版資料は [`../legacy/`](../legacy/) に置き、現行要件の根拠として扱わない。
- 呼称は「セミナー資料」に統一する。
