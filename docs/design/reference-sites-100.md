## VEXUM Academyで特に取り入れたい共通パターン

- **Heroは説明ではなく期待感を作る**：最初の1画面は会社説明を詰め込まず、強いコピー・映像・抽象3D・実際の成果物などで「続きを見たい」を作る。
- **1画面1メッセージ**：Appleや大企業採用サイトのように、重要な概念ほど余白を取り、情報を一度に出しすぎない。
- **実物を見せる**：Linear / Vercel / Stripe / Cursor / Lovableのように、説明文よりUI・コード・生成結果・デモを前面に出す。
- **スクロールをストーリーにする**：VEXUM → IT → LLM → AI → DEFINE → BUILD の順に、世界が開いていく感覚を作る。
- **学習は読むだけにしない**：Brilliant / Codecademyのように、クイズ・入力・比較・デモ・試作をページ内に置く。
- **高級感と遊びのバランス**：採用LPの品格を土台にし、Mission / Progress / Final Missionなどのゲーム要素は限定的に使う。

## 使い方

デザインを1サイト丸ごと模倣するのではなく、以下のようにパーツ単位で組み合わせる。

- **TOP / Hero**：三菱地所、Apple、LayerX、MasterClass
- **ストーリー構成**：三井不動産、National Geographic、NYT Interactive
- **教材内部UI**：Linear、Vercel、Notion、AREA 17
- **AI / コーディングデモ**：Cursor、Lovable、ElevenLabs、Runway
- **Mission / Progress**：Brilliant、Duolingo、Codecademy
- **大胆なモーション**：Framer、Locomotive、Active Theory、Immersive Garden
- **上質なタイポ・余白**：NANIMONO、Anthropic、Aesop、Kinfolk

### 推奨する最終ミックス

**三菱地所 NANIMONOの世界観 × 三井不動産のCASE STORY × Linear/VercelのTech UI × Brilliant/Codecademyのインタラクティブ学習** を基本線とする。

トップは大企業採用サイトのように感情を動かし、教材本文はTechプロダクトのように整理し、ワークは学習サービスのように実際に触れる構成にする。
