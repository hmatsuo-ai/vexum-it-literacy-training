- [01｜日本の採用・企業サイト 25社](./01_recruiting-japan.md) — 250案
- [02｜Tech / AI / SaaS 25社](./02_tech-ai-saas.md) — 250案

**合計：100サイト / 1,000 UIアイデア**

## 抽出軸

- Hero / First View
- Typography
- Color / Background
- Whitespace / Grid
- Navigation
- Cards / Bento / Gallery
- Scroll / Motion / Transition
- Interaction / Demo
- Storytelling / Progress
- VEXUMへの転用方法

## 使用原則

1サイトをそのままコピーせず、複数サイトから良い部品を組み合わせて独自のDesign Systemへ再構成します。
