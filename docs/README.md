# Documentation

このディレクトリは、Web教材の実装コード以外の文書を役割別に管理します。

## 構成

- [`requirements/`](./requirements/) — **内容要件の正本**。カリキュラムやテーマ要件はここだけで管理する。
- [`design/`](./design/) — デザイン調査、参考サイト、UIアイデア、汎用デザインパターン。
- [`legacy/`](./legacy/) — 旧版資料。履歴・比較用であり、現在の要件定義には使用しない。

## 管理ルール

1. 要件とデザイン資料を同じフォルダへ混在させない。
2. 現行の内容判断は `requirements/` の統合要件定義書を優先する。
3. 旧資料は削除せず `legacy/` に隔離し、正本と誤認されないようにする。
4. デザイン調査は `design/` へ集約する。
