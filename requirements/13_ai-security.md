# Theme 13｜AI・情報セキュリティ

- 区分：CORE
- 想定受講段階：AIを業務利用する前

## 1. このテーマの目的

AIを「使わない」ためではなく、情報・権限・出力のリスクを理解し、安全に業務利用するための判断基準を身につける。

## 2. 対象者・前提知識

Theme 09を受講済みの全受講者。

## 3. 到達目標

- AI利用時の入力・出力・システム／権限の3方向のリスクを説明できる。
- 入力してよい情報と、確認・匿名化・禁止が必要な情報を分類できる。
- AIの出力を検証してから利用・共有できる。
- 公式に承認されていないAIや個人アカウントを業務に使うリスクを説明できる。

## 4. 必須学習内容

- 入力リスク：機密情報、個人情報、顧客情報、認証情報、契約情報
- 出力リスク：ハルシネーション、誤引用、著作権・権利、偏り、誤送信
- システム／権限リスク：過剰権限、外部連携、公開リンク、誤ったアカウント、エージェントの自動操作
- 公開情報／社内限定／機密／個人情報などの分類
- シャドーAIの考え方
- パスワード、APIキー、認証コードをAIへ入力しないこと
- 必要最小限の権限
- 「入力前に確認 → AI利用 → 出力検証 → 人が承認 → 共有」の基本フロー
- 最新のVEXUM情報セキュリティポリシーが教材より優先されること

## 5. 扱わない内容

- 「有料AIなら何を入力しても安全」という説明
- 実在する秘密情報を教材例として掲載すること
- 法的判断をAIだけに任せること

## 6. 推奨学習構成

守る対象 → 3つのリスク → 情報分類 → 権限 → 出力確認 → ケース演習

## 7. 実務ケース

顧客から受け取った従業員一覧をAIで整理したい場合、何を確認し、どの情報を加工し、どの環境を使うべきか判断する。

## 8. 演習

複数のデータ例を「そのまま入力可／匿名化・加工後なら可／承認が必要／入力不可」に分類し、理由を書く。

## 9. 理解度確認

製品名ではなく、ケースごとに「何がリスクか」「どの対策を先に行うか」を答えさせる。

## 10. 更新対象情報

社内ポリシー、承認済みAI一覧、契約プラン、保存・学習設定、各AIのデータ取扱い、セキュリティ事故事例。

## 11. 他テーマとの依存関係

- 次に学ぶ候補：Theme 12、14〜18、21、22

## 12. 完成条件

情報システム・管理担当の正式方針と整合し、受講者が具体的ケースで入力可否と必要な確認を判断できる。
