# Theme 07｜LLMとは何か

- 区分：SEMINAR-CORE
- 想定受講段階：PC・Web・クラウド等の基礎を理解した後
- 教材化時の想定：**LLMを約4ページ**

## 1. このテーマの目的

生成AIを使ううえで中心となる**LLM（Large Language Model）が何をしているものなのか**を、IT・AI初心者でも理解できる状態を作る。

このテーマでは、LLMの内部技術を細かく学ばない。

受講者が最終的に次を自分の言葉で説明できればよい。

- LLMとは何か
- なぜ自然な文章を作れるのか
- LLMは検索エンジンや正解データベースではないこと
- LLMは何でも最新・正確に知っているわけではないこと
- なぜもっともらしい間違いを出すことがあるのか
- なぜAIの回答を人が確認する必要があるのか

数式、プログラミング、機械学習の専門知識は前提にしない。

---

## 2. LLMは約4ページ使って理解させる

### Page 1｜LLMとは何か

LLMは、**大量の文章から、言葉の使われ方や文章のパターンを学習した大規模な言語モデル**である。

多くの対話型生成AIでは、このLLMが文章の理解・生成の中心を担っている。

重要なのは、LLMが質問への完成した答えを巨大なデータベースからそのまま取り出しているわけではないこと。

入力された質問や会話の流れをもとに、その場で回答文を作っている。

#### このページで理解してほしいこと

**LLMは「答えを保存している箱」ではなく、学習した言語パターンを使って文章を生成するモデル。**

---

### Page 2｜なぜ自然な文章を作れるのか

LLMは非常に多くの文章から、

- 言葉がどのような場面で使われるか
- 文と文がどのようにつながるか
- 質問に対してどのような回答が続くか
- 説明、要約、比較、文章作成などのパターン

を学習している。

そのため、単語を無関係に並べるのではなく、質問や前後の文脈に合った自然な文章を生成できる。

初心者には、

> 「昔々、あるところに」

の続きを人間が自然に予想できるように、LLMも非常に大きな規模で文章の続きを判断している、というイメージで説明する。

内部構造や技術名称には進まない。

#### このページで理解してほしいこと

**大量の文章から言葉と文脈のパターンを学習しているから、人間らしい文章を作れる。**

---

### Page 3｜LLMは何を知っていて、何を知らないのか

LLMは学習した内容をもとに回答するが、何でも正確・最新に知っているわけではない。

特に次を理解させる。

- 学習されていない情報は正確に答えられない場合がある
- 最新情報は、そのLLMだけでは把握していない場合がある
- 社内資料や自分のファイルを、最初から知っているわけではない
- 質問に必要な情報が不足していると、推測を含むことがある

現在のAIアプリには、Web検索、ファイル参照、外部サービスとの接続等が最初から組み込まれている場合がある。

ここでは仕組みの名前を覚えさせず、次だけ区別する。

**LLMがもともと持っている能力・知識**

と

**AIアプリがその場で新しく参照した情報**

は別である。

RAG、Tool / Function Calling等の内部方式は扱わない。MCP等の接続方式は後続テーマで扱う。

#### このページで理解してほしいこと

**「AIが答えた」ことと、「今、正しい情報を確認して答えた」ことは同じではない。**

---

### Page 4｜なぜLLMは間違えるのか

LLMは、必ず正しい事実だけを返す装置ではなく、**質問や文脈に合う自然な回答を生成するモデル**である。

そのため、正しい情報が不足していても、文章として自然な回答を作ってしまうことがある。

次の流れで理解させる。

**大量の文章からパターンを学習している**
→ **自然な文章を作れる**
→ **情報が足りなくても自然な文章を作れてしまう**
→ **もっともらしい間違いが起こることがある**

これが、生成AIの回答を人が確認する必要がある大きな理由である。

数字、日付、固有名詞、根拠、重要な判断は特に確認する。

#### このページで理解してほしいこと

**文章が自然であることと、内容が正しいことは別。**

---

## 3. 4ページを通して理解させる一本の流れ

受講者には、次を説明できる状態を目指す。

**LLMは大量の文章から言葉と文脈のパターンを学習している**
→ **質問に対して、そのパターンを使って回答文を生成する**
→ **検索結果や保存済みの正解をそのまま返しているわけではない**
→ **何でも最新・正確に知っているわけではない**
→ **そのため、もっともらしい間違いも起こる**
→ **必要な情報を与え、最後は人が確認する**

この流れが理解できれば、LLM基礎の目的を達成したものとする。

## 4. 実演

### 実演1｜文章の続きを考える

「昔々、あるところに」等の続きを受講者にも予想してもらう。

複数の自然な候補があることを確認し、LLMも大量の言語パターンをもとに回答を作っていることへつなげる。

### 実演2｜自然だが間違った回答

情報が不足した質問や架空の内容についてAIへ質問し、自然な文章でも事実とは限らないことを確認する。

その後、正しい資料や確認可能な情報を与えた場合との違いを見る。

## 5. 理解度確認

次を自分の言葉で説明できるか確認する。

1. LLMとは何か
2. なぜ自然な文章を作れるのか

4. LLMはなぜ何でも最新・正確に答えられるわけではないのか
5. なぜもっともらしい間違いを出すことがあるのか
6. なぜ人による確認が必要なのか

技術用語の暗記問題は作らない。

## 6. 扱わない内容

このテーマでは、以下を学習・テスト対象にしない。

- トークンの詳細
- Embedding
- Transformer / Attention
- Training / Inference
- コンテキストウィンドウの仕様
- temperature等の生成パラメータ
- ニューラルネットワークの内部構造
- RAG
- Tool / Function Calling
- 数式、行列演算、勾配降下法等
- モデル名、パラメータ数、ベンチマーク順位

LLMの理解に必要であれば講師が補足してもよいが、教科書の中心にはしない。
