# Theme 07｜AIとは何か

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 02の次

## 1. このテーマの目的

AIを難しい技術用語として覚えるのではなく、**「AIは何が得意で、何が苦手で、仕事の中で人とどう分担して使うものか」**を理解する。

セミナー参加者がAIに対して過度に期待したり、逆に難しそうだと感じたりせず、以降のAIツール・プロンプト学習へ自然に進める導入とする。

## 2. 対象者・前提知識

Theme 01〜02を受講済み。AI経験は問わない。

## 3. 到達目標

- AI・生成AI・LLMの違いを厳密な定義ではなく、用途ベースで説明できる。
- 生成AIが文章・画像・要約・アイデア・コード等を作れることを理解する。
- AIの回答は常に正しいわけではなく、確認が必要であることを説明できる。
- 「AIに任せる部分」と「人が判断する部分」を分けて考えられる。
- AIを仕事を奪う存在／万能な存在のどちらかに単純化せず、仕事の進め方を変える道具として捉えられる。

## 4. 必須学習内容

### AIの全体像
- AIとは、人が行っていた認識・予測・生成・判断補助などをコンピュータで実現する技術群であること
- 生成AIは、文章・画像・音声・動画・コードなどを新しく生成できるAIであること
- LLMは、文章の理解・生成を中心に使われる生成AIの基盤の一つであること

### 生成AIでできること
- 情報整理・要約
- アイデア出し
- 文章作成・修正
- 調査の補助
- データ整理・分析補助
- 画像・動画等の生成
- コード生成・開発支援

### AIの限界
- もっともらしい誤情報を出すことがある
- 情報が不足すると推測することがある
- 指示の与え方によって結果が変わる
- 最終判断・責任をAIへ丸投げできない
- 機密情報等を何でも入力してよいわけではない

### 人とAIの役割分担

**AI：速く考える・作る・整理する**

**人：目的を決める・状況を理解する・判断する・確認する・責任を持つ**

この役割分担をVEXUMの仕事にも接続する。

## 5. 扱わない内容

- AI研究史の詳細
- 数学・ニューラルネットワークの詳細
- モデル名やベンチマーク順位の暗記
- 「AIで人間の仕事が全部なくなる」といった極端な予測
- 特定AI製品の詳細操作

## 6. 推奨学習構成

**身近なAI → 生成AIとは → 何ができるか → 何ができないか → 人とAIの役割分担 → VEXUMでどう使うか**

説明だけで終わらず、実際のAI出力を1〜2例見せる。

## 7. 実務ケース

顧客から「毎週作っている報告書に2時間かかる」と相談されたケースを提示する。

受講者に、
1. AIに任せられそうな部分
2. 人が確認・判断すべき部分
3. AIを使う前に確認したいこと
を考えてもらう。

## 8. 演習

複数の業務を提示し、「AIに任せる／人が行う／AIと人で共同する」に分類する。

正解暗記ではなく、なぜそう考えたかを説明させる。

## 9. 理解度確認

次を自分の言葉で説明できるか確認する。

1. 生成AIとは何か
2. AIの得意なこと・苦手なこと
3. なぜAIの出力を人が確認する必要があるか
4. VEXUMの仕事でAIと人がどう役割分担するか
