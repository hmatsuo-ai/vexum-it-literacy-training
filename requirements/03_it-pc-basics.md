# Theme 03｜IT・PCの基礎

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 02の次、AI講座の前

## 1. このテーマの目的

受講者が、PC・ファイル・クラウド・Webサービスを別々の用語として暗記するのではなく、**「データがどこにあり、どこで処理され、どうやって別のサービスへ渡るのか」**を一続きで理解する。

最終的には、

**PC → ファイル → クラウド → 業務ツール → Webサービス → AI**

という流れを自分の言葉で説明できる状態を目指す。

## 2. 対象者・前提知識

Theme 01〜02を受講済みの新規受講者。

IT経験は問わない。「RAMとストレージの違い」「ローカルとクラウドの違い」「ファイルがどこに保存されているか」が分からない受講者がいる前提で設計する。

## 3. 到達目標

- CPU、RAM、ストレージ、OSの役割を大まかに説明できる。
- ファイル、フォルダ、拡張子、保存場所を説明できる。
- ローカル保存とクラウド保存の違いを説明できる。
- アップロード、ダウンロード、同期、共有の違いを説明できる。
- ブラウザ、URL、サーバー、クライアントの関係を大まかに理解する。
- アカウント、ログイン、認証、閲覧権限、編集権限を区別できる。
- Google WorkspaceとMicrosoft 365の代表的な対応関係を知っている。
- GUIとCLIがPCを操作する2つの代表的な方法だと知っている。
- AIへ情報を渡すには入力・アップロード・検索・接続等が必要だと理解する。

## 4. 必須学習内容

### 4.1 PCの基本｜処理する場所と保存する場所

- **CPU**：計算や命令処理を行う中心部分
- **RAM（メモリ）**：いま使っている情報を一時的に置く作業場所
- **ストレージ**：ファイルやアプリを保存する場所
- **OS**：PC全体を管理し、アプリやファイルを使えるようにする基本ソフトウェア

初心者向けには、

**CPU＝作業する人 / RAM＝作業机 / ストレージ＝保管棚 / OS＝全体を管理する仕組み**

程度の比喩でよい。

重要なのは、**メモリと保存容量は別物**であること。

### 4.2 ファイルとフォルダ

- ファイルとフォルダ
- ファイル名と拡張子
- 保存場所
- コピー、移動、削除
- アップロード、ダウンロード

代表形式は役割だけ紹介する。

- PDF：見た目を保った文書
- Word / Googleドキュメント：文章
- Excel / Googleスプレッドシート：表・数値
- PowerPoint / Googleスライド：プレゼン資料
- CSV：単純な表データ
- PNG / JPG：画像

拡張子を大量に暗記させない。

### 4.3 ローカルとクラウド

#### ローカル

自分のPC・端末側に保存されている状態。

#### クラウド

インターネット経由で外部のサーバー側にデータを保存・利用する考え方。

次を区別する。

- ローカルにしかないファイル
- クラウドにあるファイル
- クラウドのファイルをダウンロードしたコピー
- 同期されている状態
- 他者へ共有されている状態

**画面上で見えていることと、自分のPCに保存されていることは同じではない。**

### 4.4 Webの基本

- インターネット：コンピュータ同士をつなぐ大きなネットワーク
- Web：インターネット上でページやサービスを利用する仕組み
- ブラウザ：Webページ・Webアプリを利用するアプリ
- URL：Web上の場所を示す情報
- クライアント：利用者側のPC・ブラウザ・アプリ
- サーバー：データや機能を提供する側

基本構造は、

**自分のPC・ブラウザ → インターネット → サーバー → 結果が返る**

という図で説明する。

DNS、TCP/IP等の詳細には進まない。

### 4.5 アカウント・ログイン・権限

- アカウント
- ログイン
- 認証
- 個人アカウントと会社アカウント
- 閲覧権限
- 編集権限
- 共有リンク

**データが存在すること**と**自分にアクセス権があること**は別であると理解させる。

複数アカウントを使う場合は「いまどのアカウントで操作しているか」を確認する。

### 4.6 業務ツールへの橋渡し｜Google系とMicrosoft系

ここは**5〜10分の短い紹介**に留める。

仕事では、ファイルやクラウドの知識がそのまま業務ツールにつながることを理解させる。

| やりたいこと | Google Workspace | Microsoft 365 |
| --- | --- | --- |
| 文書 | Googleドキュメント | Word |
| 表計算 | Googleスプレッドシート | Excel |
| プレゼン | Googleスライド | PowerPoint |
| クラウド保存 | Google Drive | OneDrive / SharePoint |
| メール | Gmail | Outlook |
| 会議 | Google Meet | Teams |

この場では製品機能を詳しく覚えさせない。

最低限、次だけ理解させる。

- Google系もMicrosoft系も、文書・表・資料・メール・共有等の仕事を行うための環境である。
- WordやExcelはローカルにもクラウドにも保存できる。
- Googleドキュメント等はクラウド中心で使うことが多い。
- 顧客・会社が指定する環境を優先する。
- 詳細な比較はTheme 12の入社後教材で扱う。

### 4.7 GUIとCLI｜PCを操作する方法が複数ある

エージェント理解の前提として**1〜2分程度**だけ扱う。

- **GUI**：画面のボタンやアイコンを見て操作する方法
- **CLI**：文字でPCへ指示する方法

例えば「フォルダを作る」ことは、画面からでも文字による指示からでも実行できる。

コマンドは覚えさせない。Theme 03では、**PCは画面操作以外の方法でも操作できる**と知れば十分。

### 4.8 IT基礎からAIへつなげる

生成AIもWebサービス・アプリとして提供されることが多い。

AIがPCやクラウドにある全情報を最初から自由に見られるわけではない。

AIへ情報を渡す代表的な方法は、

- 文章を入力する
- ファイルをアップロードする
- Webを検索させる
- 許可したクラウドサービス等を接続する

である。

接続方式の専門用語や内部仕様はここでは扱わない。

Theme 03では、**AIに情報を使わせるには何らかの入力・参照・接続が必要**と理解させる。

## 5. 扱わない内容

- CPU・RAM・SSDの細かな規格や性能比較
- OS内部構造
- TCP/IP、DNS、ポート番号等のネットワーク詳細
- CLIコマンドの暗記
- API・MCP等の技術仕様
- プログラミング文法
- Google Workspace / Microsoft 365の詳細機能
- セキュリティ規程の詳細

## 6. 推奨学習構成

**PCの中身 → ファイル → 保存場所 → ローカル／クラウド → Web → アカウント・権限 → GWS/M365対応表 → GUI/CLIを一言 → AIへ情報が渡るまで**

## 7. 実務ケース

> PCの「ダウンロード」フォルダにExcelファイルがあります。この内容をAIに要約してもらいたい。

考えること：

1. ファイルはいまどこにあるか
2. AIは現時点で見られるか
3. どうすれば渡せるか
4. クラウドへ置いた場合は何が変わるか
5. 会社・顧客のアカウントや権限は正しいか
6. AIの回答後に元ファイルを確認する必要があるのはなぜか

## 8. 理解度確認

1. RAMとストレージの違い
2. ローカルとクラウドの違い
3. アップロードとダウンロードの違い
4. ブラウザとWebサービスの関係
5. 閲覧権限と編集権限の違い
6. DocsとWord、SheetsとExcelが大まかに何へ対応するか
7. GUIとCLIは何が違うか
8. PCのファイルをAIが最初から読めるわけではない理由

正式定義の丸暗記ではなく、具体的な状況を説明できることを評価する。
