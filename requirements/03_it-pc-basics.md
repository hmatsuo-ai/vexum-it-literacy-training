# Theme 03｜IT・PCの基礎

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 02の次、AI講座の前

## 1. このテーマの目的

受講者が、PC・ファイル・クラウド・Webサービスを別々の用語として暗記するのではなく、**「データがどこにあり、どこで処理され、どうやって別のサービスへ渡るのか」**を一続きで理解する。

AI講座へ入る前に、ChatGPT等も突然現れた魔法の箱ではなく、PC・ブラウザ・クラウド・アカウント・ファイルとつながるITサービスであることを理解できる土台を作る。

最終的には、

**PC → ファイル → クラウド → Webサービス → AI**

という流れを自分の言葉で説明できる状態を目指す。

## 2. 対象者・前提知識

Theme 01〜02を受講済みの新規受講者。

IT経験は問わない。「RAMとストレージの違い」「ローカルとクラウドの違い」「ファイルがどこに保存されているか」が分からない受講者がいる前提で設計する。

## 3. 到達目標

- CPU、RAM、ストレージ、OSの役割を大まかに説明できる。
- ファイル、フォルダ、拡張子、ファイルパスの意味を説明できる。
- ローカル保存とクラウド保存の違いを説明できる。
- アップロード、ダウンロード、同期、共有の違いを説明できる。
- ブラウザ、Webサイト、URL、サーバー、クライアントの関係を大まかに説明できる。
- ログイン、アカウント、認証、閲覧権限、編集権限の違いを理解する。
- 「このデータはいまどこにあるか」「誰が見られるか」を確認する習慣を持つ。
- AIへファイルやクラウド情報を渡すとき、どのような経路でAIが情報へアクセスするかを大まかに説明できる。

## 4. 必須学習内容

### 4.1 PCの基本｜処理する場所と保存する場所

PCの構成は、細かな性能表ではなく役割で理解させる。

- **CPU**：計算や命令処理を行う中心部分
- **RAM（メモリ）**：いま使っている情報を一時的に置く作業場所
- **SSD・ストレージ**：ファイルやアプリを保存しておく場所
- **OS**：ハードウェア、アプリ、ファイル等を管理し、PCを使える状態にする基本ソフトウェア

初心者向けには、

**CPU＝作業する人 / RAM＝作業机 / ストレージ＝保管棚 / OS＝全体を管理する仕組み**

程度の比喩を使ってよい。

重要なのは、**メモリと保存容量は別物**であることを理解させること。

### 4.2 ファイルとフォルダ

- ファイルとは何か
- フォルダとは何か
- ファイル名と拡張子
- ファイルパス
- コピー、移動、削除
- アップロード、ダウンロード

代表的な形式は役割だけ紹介する。

- PDF：レイアウトを保った文書
- Word / Googleドキュメント系：文章
- Excel / Googleスプレッドシート系：表・数値
- CSV：表データを単純なテキスト形式で保存
- PNG / JPG等：画像

拡張子を大量に暗記させない。

### 4.3 ローカルとクラウド

#### ローカル

自分のPCや端末側に保存されている状態。

#### クラウド

インターネット経由で利用する外部のサーバー側にデータを保存・処理する考え方。

Google Drive等を例に、次を区別する。

- ローカルにしかないファイル
- クラウドにあるファイル
- クラウドのファイルをローカルへダウンロードした状態
- 同期によって複数環境から同じデータを扱う状態
- 共有によって他者もアクセスできる状態

**「画面上で見えている」ことと「自分のPCに保存されている」ことは同じではない**ことを理解させる。

### 4.4 Webの基本

専門的なネットワーク講義にはせず、Webサービスを使うために必要な範囲だけ扱う。

- インターネット：コンピュータ同士をつなぐ大きなネットワーク
- Web：インターネット上でページやサービスを利用する仕組みの一つ
- ブラウザ：WebページやWebアプリを利用するためのアプリ
- URL：Web上の場所を示す情報
- クライアント：利用者側のPC・ブラウザ・アプリ
- サーバー：データや機能を提供する側

基本構造は、

**自分のPC・ブラウザ → インターネット → サーバー → 結果がブラウザへ返る**

という図で説明する。

DNS、TCP/IP、HTTPヘッダー等の詳細には進まない。

### 4.5 アカウント・ログイン・権限

Webサービスでは「誰が使っているか」と「何をしてよいか」が重要になる。

- アカウント
- ログイン
- 認証
- 個人アカウントと会社アカウント
- 閲覧権限
- 編集権限
- 共有リンク

Google Drive等を例に、

**データが存在すること**と**自分にアクセス権があること**は別であると理解させる。

また、複数アカウントを利用している場合は「いまどのアカウントで操作しているか」を確認する必要があることを扱う。

### 4.6 IT基礎からAIへつなげる

このテーマの最後では、ここまでの知識をAIへ接続する。

ChatGPT等もWebサービスとして利用されることが多く、AIが自分のPCやクラウドにあるすべての情報を最初から自由に見られるわけではない。

AIが情報を使う場合は、例えば次の経路がある。

- ユーザーが文章を入力する
- ファイルをアップロードする
- Web上の情報を検索する
- Google Drive等のクラウドサービスを接続する
- ConnectorやMCP等を通じて外部データ・ツールへ接続する

ConnectorやMCPの技術詳細は後続テーマで扱う。

Theme 03では、**AIに情報を渡すには、何らかの入力・アップロード・接続が必要**という考え方まで理解させる。

## 5. 扱わない内容

- CPUのクロック数・コア数等の細かな性能比較
- RAM規格、SSD規格等のハードウェア詳細
- OS内部構造
- BIOS / UEFI
- TCP/IP、DNS、ポート番号等のネットワーク詳細
- サーバー構築
- コマンドライン操作
- プログラミング文法
- API・MCPの技術仕様
- セキュリティ規程の詳細

**ITエンジニアになるための基礎講義ではなく、AI・クラウド・業務ツールを理解して使うための最低限のIT基礎**に限定する。

## 6. 推奨学習構成

**PCの中身 → ファイル → 保存場所 → ローカルとクラウド → Webサービス → アカウントと権限 → AIへ情報が渡るまで**

用語を順番に説明するだけでなく、一つのデータが移動する様子を追跡する。

## 7. 実務ケース

### ケース｜ExcelファイルをAIに読ませたい

受講者へ次の状況を提示する。

> PCの「ダウンロード」フォルダにExcelファイルがあります。この内容をAIに要約してもらいたい。

次を順番に考えさせる。

1. Excelファイルはいまどこにあるか
2. AIは現時点でそのファイルを見られるか
3. どうすればAIへ渡せるか
4. ファイルをGoogle Driveへ置いた場合、何が変わるか
5. DriveをAIへ接続した場合、何を確認すべきか
6. AIが回答した後も、元ファイルを確認する必要があるのはなぜか

このケースをTheme 07以降のAI学習への橋渡しにする。

## 8. 演習

### 演習1｜データはどこにある？

複数の例について、

- ローカル
- クラウド
- 両方にコピーがある
- 判断できない

のどれかを答え、理由を説明する。

### 演習2｜データの流れを書く

次の処理を矢印で表現させる。

> PCにあるPDFをブラウザからAIへアップロードし、要約してもらう。

例：

**PCのストレージ → ブラウザ → インターネット → AIサービス → 回答 → ブラウザ**

細かな技術仕様ではなく、情報がどこからどこへ移動しているかを意識させる。

## 9. 理解度確認

次を自分の言葉で説明できるか確認する。

1. RAMとストレージは何が違うか

5. サーバーは何をするものか
6. 閲覧権限と編集権限は何が違うか

用語の正式定義を丸暗記させるのではなく、具体的な状況を説明できることを評価する。
