# Theme 08｜生成AIに共通する使い方・性能・外部連携

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 07「LLMとは何か」の次

## 1. このテーマの目的

特定のAI製品を覚えるのではなく、**どの生成AIを使う場合にも共通する判断軸**を理解する。

Theme 07でLLMそのものを理解した後、このテーマでは実際のAIアプリを使うときに共通する次の考え方を扱う。

- 速さと深さの使い分け
- 通常回答とリサーチの違い
- ファイルや外部情報を使う場合の考え方
- MCP等による外部接続
- AIの出力・操作を人が確認すること

製品名、モデル名、料金、UIの暗記は行わない。

## 2. 到達目標

- 軽量・低推論の利用は速い傾向があることを説明できる。
- 高性能・高推論の利用は時間がかかる代わりに複雑な検討に向く傾向を説明できる。
- 高性能なAIでも、自動的にWebを調査するとは限らないことを理解する。
- AIがファイルやWeb等を参照した場合、元情報を確認する必要性を理解する。
- AIが外部サービスを利用するには接続と権限が必要であることを説明できる。
- MCPを、AIと外部ツール・データを接続する共通的な仕組みの一つとして大まかに説明できる。
- AIの出力・外部操作を無確認で採用しない。

## 3. 必須学習内容

### 3.1 速さと深さ

生成AIには、用途に応じて速さを優先する使い方と、時間をかけて深く検討する使い方がある。

初心者には次のように説明する。

- **軽量・低推論**：速い傾向。短い質問、文章修正、簡単な整理などに向く。
- **高性能・高推論**：時間がかかる傾向。複雑な比較、分析、計画、難しい問題などに向く。
- **リサーチ**：Webや資料を実際に確認するため通常回答より時間がかかるが、根拠を確認しながら回答できる。

ただし、**遅いほど必ず正しい、高性能なら必ず調査する**という意味ではない。

### 3.2 AIが参照する情報

AIアプリは状況に応じて、

- ユーザーが入力した文章
- 添付したファイル
- Web上の情報
- 接続された外部サービス

などを利用できる場合がある。

重要なのは、**AIが何を根拠に答えているかを確認すること**。

数字、固有名詞、日付、重要な判断は元情報へ戻って確認する。

### 3.3 外部サービスとの接続

AIが外部サービスを利用する場合は、次を確認する。

1. 何のサービスへ接続するか
2. どのアカウントで接続するか
3. 何のデータを読めるか
4. 書き込み・送信・削除等が可能か
5. 人の承認が必要か

### 3.4 MCP

MCPは、**AIが外部のツールやデータを利用するための共通的な接続方法・ルールの一つ**として紹介する。

初心者には、

**AI ↔ MCP等の接続手段 ↔ 外部ツール・データ**

という関係だけ理解させる。

API等との技術的な違いは発展テーマで扱う。

### 3.5 紹介コラム｜NotebookLM

NotebookLMは、**自分が指定した資料を中心に質問・要約・比較・整理するAI活用の代表例**として短く紹介する。

伝える内容は次に限定する。

- PDF、Webページ、文書等の資料をまとめて扱える。
- 与えた資料を中心に質問・要約・比較できる。
- 回答の根拠を元資料へ戻って確認する使い方に向いている。
- 大量の資料を理解・整理するときの選択肢になる。
- 一般的な生成AIでも類似の資料読解は可能である。
- 資料を与えれば必ず正しいわけではなく、元資料の確認が必要。

**必須ツールではなく、知っておくと便利な選択肢の一つ**とする。

教材は1ページ以内、説明は5分以内。NotebookLM単体の操作テストは行わない。

## 4. 扱わない内容

- ChatGPT、Claude、Gemini等の一般的な生成AI製品の個別紹介
- 製品別の機能一覧
- 固定的なAIランキング
- モデル名・料金・UIの暗記
- 「このAIは文章向け、このAIはコード向け」等の固定的な決めつけ
- RAGやTool / Function Callingの内部技術説明

## 5. 推奨学習構成

**LLMの理解 → 速さと深さ → リサーチ → ファイル・外部情報 → MCP → NotebookLM紹介 → 権限と確認**

製品名から説明を始めない。

## 6. 理解度確認

次を自分の言葉で説明できるか確認する。

1. 速いAI利用と深く考えるAI利用をなぜ使い分けるのか
2. 高性能なAIでも、なぜ必ず外部情報を調査するとは限らないのか
3. AIがファイルやWebを参照した場合、何を確認すべきか
4. MCPは何のための仕組みか
5. 外部サービスへ接続するとき何を確認すべきか

NotebookLMという製品名そのものはテスト対象にしない。

## 7. 完成条件

- 特定AI製品の説明に依存していない。
- 速さと深さのトレードオフを初心者が理解できる。
- リサーチと通常回答を区別できる。
- 外部情報・ツールを使う場合の権限と確認を理解できる。
- NotebookLMは短い紹介に留まっている。
