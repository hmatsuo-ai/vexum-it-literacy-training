# Theme 08｜生成AIの主要ツールと共通する使い方

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 07の次

## 1. このテーマの目的

生成AIの主要ツールとして、**GPT（ChatGPT）とClaudeを二大ツールとして扱う**。

両者には設計思想、UI、外部連携、モデル特性、細かな機能等の違いはあるが、VEXUMの受講者が日常業務で使うレベルでは、**文章作成、要約、調査補助、資料読解、アイデア出し、コード生成、データ整理など、できることの重なりが非常に大きい**ことを理解させる。

したがって、「GPTはこれ専用、Claudeはこれ専用」と固定的に覚えさせるのではなく、**どちらも基本的には幅広い仕事に使える。そのうえで、必要に応じて使いやすさ・連携環境・回答傾向・利用可能な機能から選ぶ**という考え方を身につける。

## 2. 対象者・前提知識

Theme 07「AIとは何か」を受講済み。特定のAIサービスの利用経験は問わない。

## 3. 到達目標

- GPT（ChatGPT）とClaudeが、VEXUMで扱う主要な生成AIツールであることを理解する。
- GPTとClaudeの基本的な業務能力には大きな重なりがあることを説明できる。
- 両者を固定的な得意・不得意だけで分類せず、実際に試して選ぶ考え方を持てる。
- 生成AIには、応答速度を優先する使い方と、時間をかけて深く考える使い方があることを説明できる。
- 「高性能なAIだから自動的にWebを調査する」とは限らず、検索・リサーチ機能の有無や設定を確認する必要があると理解する。
- AIが外部のデータやツールを使うには接続手段と権限が必要であることを説明できる。
- MCPを、AIと外部ツール・データをつなぐ共通的な仕組みの一つとして説明できる。
- AIの出力をそのまま正解とせず、人が確認する箇所を判断できる。

## 4. 必須学習内容

### 4.1 二大ツール｜GPTとClaude

セミナーでは、一般的な生成AIの代表として以下の2つを中心に扱う。

- **GPT / ChatGPT**
- **Claude**

この2つについて、細かな性能差を暗記させるのではなく、まず次を理解させる。

> **VEXUMの通常業務で使う範囲では、GPTとClaudeで「できること」の違いは比較的小さい。**

どちらでも、主に以下のような業務ができる。

- 質問・壁打ち
- 文章作成・修正
- 要約
- 資料読解
- アイデア出し
- 調査の補助
- 表・データの整理
- コード生成・修正
- 要件整理
- 提案や資料のたたき台作成

### 4.2 GPTとClaudeの違いの扱い方

GPTとClaudeに違いがないという意味ではない。

違いが出やすい要素として、次を紹介する。

- 回答の表現や傾向
- モデルや推論モード
- ファイル・資料の扱い方
- Web検索・リサーチ機能
- コーディング支援機能
- 外部サービスとの連携
- UIやワークフロー
- 利用可能な会社契約・権限

ただし、これらは更新が速いため、**「GPTは必ず○○向き」「Claudeは必ず○○向き」と固定しない。**

受講者には、

**同じ仕事を両方に試す → 出力を比較する → その時点で使いやすい方を選ぶ**

という姿勢を身につけさせる。

### 4.3 速さと深さのトレードオフ

生成AIには、用途に応じて異なる性能・推論量・動作モードがある。

- **軽量・低推論**：応答が速い傾向。短い質問、文章修正、単純な整理などに向く。
- **高性能・高推論**：回答まで時間がかかる傾向。複雑な条件整理、比較、分析、計画、難しい問題などに向く。
- **リサーチ・外部ツール利用**：Webや接続資料を実際に確認するため、通常の対話より時間がかかるが、複数の情報を確認しながら回答できる。

重要なのは、**「遅いほど必ず正しい」「高性能なら必ず調査する」という意味ではない**こと。

速さ、深さ、利用できる情報源、必要な正確性を業務ごとに考える。

### 4.4 AIが回答を作る方法の違い

同じGPT・Claudeでも、次のように使い方が異なる。

- 与えられた質問だけで回答する
- 渡されたファイルや資料を読む
- Web等の外部情報を検索・調査する
- 接続された業務サービスから情報を取得する
- 外部ツールを使って処理・操作する

「AIが学習済みの知識として持っていること」と「AIが今その場で確認したこと」を区別する。

### 4.5 AIと外部サービスの接続

AI単体ですべての社内情報やサービスへアクセスできるわけではない。

外部サービスを利用する場合は、次を確認する。

1. 何のサービスへ接続するか
2. どのアカウントで接続するか
3. 何のデータを読めるか
4. 書き込み・送信・削除などの操作が可能か
5. 人の承認が必要か

### 4.6 MCPの基本概念

MCPは、**AIが外部のツールやデータを利用するための共通的な接続方法・ルールの一つ**として扱う。

初心者には、

**AI ↔ MCP等の接続手段 ↔ 外部ツール・データ**

という関係で説明する。

MCPそのものを暗記させるのではなく、「AIに外部の情報や操作能力を追加する場合、接続方法と権限管理が必要」という本質を理解させる。

API・Connector・MCPの技術的な違いは発展テーマで扱う。

### 4.7 共通する安全確認

- 個人情報・機密情報を入力してよい環境か
- 接続先アカウントが正しいか
- AIが参照した情報源を確認できるか
- 送信・削除・公開等の操作前に内容を確認したか
- 数字、固有名詞、日付、根拠を人が確認したか

### 4.8 紹介コラム｜NotebookLM

NotebookLMは、**自分が指定した資料を中心に質問・要約・比較・整理する「資料ベースのAI活用」の代表例**として紹介する。

ここではNotebookLMの操作方法や機能一覧を覚えさせない。

- PDF、Webページ、文書等の資料をまとめて扱えるAIツールがある。
- 与えた資料を中心に質問・要約・比較できる。
- 回答の根拠を元資料へ戻って確認する使い方に向いている。
- 大量の資料を理解・整理するときの選択肢になる。
- GPTやClaudeでも類似の資料読解は可能であり、NotebookLMだけができることとして教えない。
- 「資料を渡せば必ず正しい」わけではなく、元資料の確認は必要。

位置づけは**必須ツールではなく、知っておくと便利な選択肢の一つ**とする。

目安は教科書1ページ以内、説明時間は5分以内とし、NotebookLM単体のテストは行わない。

## 5. 扱わない内容

- GPTとClaudeの細かな機能比較表の暗記
- 「GPTは文章向け、Claudeはコード向け」等の固定的な決めつけ
- どちらか一方を絶対的に優れたAIとして教えること
- Gemini等をGPT・Claudeと同じ比重で詳細説明すること
- 製品ごとの全機能一覧
- NotebookLMの詳細な操作研修・機能暗記
- モデル名や料金プランの暗記
- 固定的なAIランキング
- ベンチマーク数値の細かな比較
- UI上のボタン位置の暗記

## 6. 推奨学習構成

**GPTとClaudeを見せる → 同じ仕事を両方にやらせる → 共通してできることを確認 → 出力や機能の違いを見る → 速さと深さの違い → 資料を渡す → 外部情報を調べる → 外部ツールへ接続する → MCPの概念 → 権限と確認**

製品比較を長時間行わず、**「主要2ツールはかなり似たことができる」ことを最初に理解させる。**

## 7. 実演

同一の業務課題をGPTとClaudeの両方に入力する。

例：

> 顧客との会議メモから、課題・確認事項・次のアクションを整理してください。

両方とも同じ種類の仕事を処理できることを確認したうえで、

- 出力の違い
- 指示への反応の違い
- 利用できる機能の違い

を短く比較する。

**どちらが勝ちかを決める演習にはしない。**

## 8. 演習

1つの業務タスクをGPTまたはClaudeで実行し、必要に応じてもう一方でも試す。

受講者に、

- 目的を達成できたか
- 出力のどこが良かったか
- 何を修正したいか
- もう一方を試す必要があるか

を考えさせる。

次を説明できるか確認する。

1. VEXUMで主要ツールとして扱う2つの生成AIは何か

3. 違いを見る場合、何を比較すべきか
4. なぜ「GPTは○○専用、Claudeは○○専用」と固定しないのか
5. 高性能なAIでも、なぜ必ず外部情報を調査するとは限らないのか
6. AIが社内データを利用するために何が必要か
7. MCPは何のための仕組みか
8. AIが外部操作を行う前に何を確認すべきか
