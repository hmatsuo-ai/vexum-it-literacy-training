# Theme 08｜実際の生成AIアプリをどう使うか

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 07「LLMとは何か」の次

## 1. このテーマの目的

Theme 07でLLMそのものを理解した後、Theme 08では**LLMが実際のAIアプリとして提供されると、何ができるようになるのか**を理解する。

セミナーではGPT / ChatGPTとClaudeを代表例として短く紹介するが、製品機能や優劣を暗記させない。

中心にするのは、どの生成AIアプリにも共通しやすい次の使い方である。

- 通常の対話
- 時間をかけて深く考える使い方
- Web検索・リサーチ
- ファイルを読ませる
- 外部サービスと接続する
- 出力の根拠や操作を人が確認する

NotebookLMは資料ベースAI活用の具体例として短く紹介する。

## 2. 到達目標

- LLMとAIアプリの違いを説明できる。
- ChatGPTとClaudeが代表的な対話型生成AIアプリであることを知っている。
- 通常対話、深い推論、検索・リサーチ、ファイル利用を目的に応じて使い分ける考え方を持てる。
- 高性能なAIでも、自動的に外部情報を調べるとは限らないことを理解する。
- AIが参照したWeb・ファイル等の元情報を確認する必要性を理解する。
- 外部サービスを接続するときは、接続先・アカウント・権限を確認する必要があると理解する。
- NotebookLMを「資料を中心に扱う選択肢の一つ」として知っている。

## 3. 必須学習内容

### 3.1 1ページで見る｜LLMからAIアプリへ

Theme 07との橋渡しとして、次の全体図を1ページ程度で見せる。

**LLM**

文章を理解・生成する中心部分

↓ AIアプリになると機能が追加される

**対話画面**：質問・文章作成・要約

**検索・リサーチ**：Web等の最新情報を確認

**ファイル利用**：PDF・文書・表等を読む

**外部接続**：許可したクラウド・業務サービス等の情報を利用

**操作・エージェント**：必要に応じて複数の作業を進める

重要なのは、

**LLMそのもの ≠ AIアプリ全体**

であること。

「AIが知っていた」のか、「AIアプリが今検索・ファイル・接続先から確認した」のかを区別する。

### 3.2 代表例｜GPT / ChatGPT と Claude

製品別講義にはしない。

- GPT / ChatGPT
- Claude

を現在広く利用される代表的な対話型生成AIの例として名前と画面を短く紹介する。

セミナーでは、

- 質問
- 文章作成
- 要約
- 資料読解
- 調査補助
- コード・データ整理の補助

など、日常業務でできることには大きな重なりがあると説明する。

「文章なら必ずClaude」「調査なら必ずChatGPT」のような固定的な得意分野は暗記させない。

### 3.3 通常対話と深く考える使い方

生成AIには、用途に応じて速さを優先する使い方と、時間をかけて複雑な問題を検討する使い方がある。

初心者には次の程度で説明する。

- **速い使い方**：短い質問、文章修正、簡単な整理等
- **深く考える使い方**：複雑な比較、分析、計画、条件の多い問題等

高性能・高推論の利用は時間がかかる傾向があるが、**遅ければ必ず正しいわけではない**。

### 3.4 通常回答と検索・リサーチ

AIが通常の対話だけで答える場合と、Web等を実際に確認してから答える場合は別である。

検索・リサーチでは、

- 最新情報
- 出典
- 複数情報の比較

を確認できる一方、通常対話より時間がかかる。

重要な情報は、AIの文章だけでなく元の情報源まで確認する。

### 3.5 ファイルを読ませる

PDF、文書、表等をAIへ渡し、

- 要約
- 比較
- 情報抽出
- 質問

を行える場合がある。

ここでも「AIへファイルを渡せば必ず正しい」とは教えない。

数字、固有名詞、重要な結論は元資料へ戻って確認する。

### 3.6 外部サービスとの接続｜具体例だけ

セミナーでは接続技術を詳しく教えない。

具体例として1つだけ示す。

> AIに会社で許可されたGoogle Driveを接続し、「○○プロジェクトの資料を探して要点をまとめて」と依頼する。

このとき重要なのは、技術名称ではなく、

1. どのGoogleアカウントを接続したか
2. AIがどの範囲を読めるか
3. 読み取りだけか、書き込みもできるか
4. 本当にその資料をAIへ渡してよいか

を確認することである。

MCPは、**このようにAIと外部ツール・データをつなぐために使われる接続方式の一つ**と一言紹介するだけにする。API・Connector・MCPの比較や技術仕様は入社後・発展学習へ回す。

### 3.7 紹介コラム｜NotebookLM

NotebookLMは、**自分が指定した資料を中心に質問・要約・比較・整理するAI活用の代表例**として紹介する。

伝える内容は次に限定する。

- PDF、Webページ、文書等の資料をまとめて扱える。
- 与えた資料を中心に質問・要約・比較できる。
- 回答の根拠を元資料へ戻って確認しやすい。
- 大量の資料を理解・整理するときの選択肢になる。
- 一般的な生成AIでも類似の資料読解は可能である。

**必須ツールではなく、知っておくと便利な選択肢の一つ**とする。

教科書1ページ以内、説明5分以内。NotebookLM単体の操作テストは行わない。

## 5. 推奨学習構成

**LLM → AIアプリ全体図 → ChatGPT / Claudeを代表例として見る → 通常対話 → 深く考える → 検索・リサーチ → ファイル → 外部接続を1例 → NotebookLM紹介 → 人が確認**

## 6. ミニ演習

同じテーマについて、

1. 通常の対話で概要を聞く
2. 必要なら深く考えさせる
3. 最新情報が必要なら検索・リサーチを使う
4. 資料があるならファイルを渡す

のどれを選ぶか考えさせる。

5. Drive等をAIへ接続するとき何を確認するか
