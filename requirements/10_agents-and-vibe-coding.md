# Theme 12｜AIエージェント・バイブコーディング

- 区分：ADVANCED / OPTIONAL
- 想定受講段階：AI基礎・プロンプト習得後

## 1. このテーマの目的

AIに「答えを返してもらう」使い方から一歩進み、AIが複数の作業を順番に進める仕組みを理解する。

その前提として、**PCには「画面を見て操作する方法（GUI）」と「文字で指示する方法（CLI）」がある**ことを知る。

GUI・CLIを使いこなすことは目的にしない。「PCは画面上のボタンだけで動いているのではなく、同じファイルやプログラムを別の方法から操作できる」と理解できればよい。

## 2. 対象者・前提知識

Theme 09〜11を受講済み。開発経験は必須としない。

GUI、CLI、ターミナル、コマンドという言葉を知らない受講者を前提にする。

## 3. 到達目標

- GUIとCLIの違いを簡単な言葉で説明できる。
- GUIとCLIは、同じPCを違う方法で操作していることを理解する。
- ターミナルは、文字でPCへ指示するときに使う代表的なアプリだと理解する。
- AIエージェントが、画面操作や文字による操作などを使って実際の作業を進める場合があることを理解する。
- 普通の対話型AIとAIエージェントの大まかな違いを説明できる。
- AIに任せる部分と、人が確認する部分を分けて考えられる。
- AIが作ったコードや変更を無確認で本番利用してはいけない理由を説明できる。

## 4. 必須学習内容

### 4.1 PCを操作する2つの代表的な方法

エージェントの説明へ入るためのPC基礎として短く扱う。

#### 画面を見て操作する方法（GUI）

- ボタン、メニュー、アイコン等を見ながら操作する
- マウスやトラックパッド等を使う
- ブラウザやファイル管理画面など、普段のPC操作の多くがこれに当たる

#### 文字で指示する方法（CLI）

- 文字で指示を入力し、PCに処理をさせる
- ターミナルというアプリから使うことが多い
- コマンド名を暗記する必要はない
- 「文字で指示しても、ファイル操作やプログラム実行ができる」と理解できればよい

#### 最も重要な理解

GUIとCLIは、別々のPCを操作するものではない。

例えばフォルダを作る場合、

- GUI：画面上で「新しいフォルダ」を選ぶ
- CLI：文字で「フォルダを作る」とPCへ指示する

方法は違うが、**最終的には同じPC上にフォルダが作られる**。

### 4.2 GUI・CLIとAIエージェントの関係

AIエージェントは、文章を返すだけでなく、許可された方法を使って実際の作業を進める場合がある。

例えば、

- ブラウザを開いてボタンを押す
- ファイルを探す
- プログラムを実行する
- 他のサービスから情報を取得する

などがある。

重要なのは、**AIエージェントも、PCやサービスを操作するための入口を使って仕事をしている**と理解することである。

### 4.3 普通のAIとAIエージェント

- 普通の対話型AIは、質問に答えたり文章を作ったりする使い方が中心
- AIエージェントは、目的に合わせて複数の作業を順番に進めることがある
- 途中で必要な情報を確認したり、別のツールを使ったりする場合がある
- 大事な操作の前には人が確認する
- うまく進められない場合は止めて人に確認する
- できる操作が多いほど、間違えたときの影響も大きくなる

### 4.4 バイブコーディング

- 日本語などで作りたいものを伝え、AIにコード作成を手伝わせる考え方
- AIが作ったものも、動作確認や見直しが必要
- 変更前の状態へ戻せるよう、変更履歴を残すことが重要

## 5. 扱わない内容

- GUIの細かな機能やショートカットの習得
- CLIコマンドの暗記
- ターミナルを自在に操作できることを到達条件にすること
- PC内部の細かな仕組み
- エージェントなら完全に自動で安全に動くという説明
- 「コードを読めなくても本番システムを作れる」という断定
- 特定サービスの細かな機能一覧

## 6. 推奨学習構成

PCはどう操作するか → GUI → CLI → 同じ操作を2つの方法で見比べる → AIエージェントが実際に操作するイメージ → 普通のAIとの違い → 人の確認 → バイブコーディング

GUI・CLIの説明は操作研修にせず、**エージェントを理解するための前提知識として短く扱う**。

## 7. 実務ケース

### ケース1：GUIとCLI

「新しいフォルダを作る」という同じ結果を、画面操作と文字による操作の両方で講師が見せる。

受講者には操作方法を覚えさせず、

- 方法は違う
- PC上で起きている結果は同じ

という点だけ確認させる。

### ケース2：AIエージェント

毎週の報告書作成を、

**情報を集める → まとめる → 下書きを作る → 人が確認する → 送る**

に分け、どこまでAIに任せるかを考える。

## 8. 演習

### 演習1：操作方法を見分ける

次のような操作例を見て、画面操作と文字による操作のどちらかを考える。

- ブラウザのボタンをクリックする
- ファイルを画面上で移動する
- ターミナルへ文字で指示する

正確な用語暗記ではなく、操作方法の違いを理解できているかを見る。

### 演習2：AIにどこまで任せるか

1つの定型業務について、

- AIに任せる作業
- 人が確認する場所
- 失敗したら止める場所
- 最後に何を確認するか

を簡単に整理する。

## 9. 理解度確認

以下を確認する。

1. GUIとCLIの違いを簡単に説明できる。
2. 方法が違っても、同じPC上のファイルやプログラムを操作できることを理解している。
3. なぜエージェントの説明でGUI・CLIを知っておくと理解しやすいのか説明できる。
4. AIに任せる作業と、人が確認すべき作業を分けて考えられる。

専門用語やコマンドを覚えているかどうかは評価しない。

## 10. 更新対象情報

AIエージェントが利用できる操作方法、ブラウザ操作、PC操作、コード実行等の提供状況。

GUI・CLIの基本的な考え方は変化しにくいため、特定のOSやアプリ名に依存しすぎないようにする。

## 12. 完成条件

- GUIとCLIが、エージェント理解の前提となるPC基礎として簡単な言葉で説明されている。
- CLIコマンド習得を要求せず、「PCを操作する別の方法」として理解できる内容になっている。
- AIエージェントが実際の操作を行うイメージが理解できる。
- 専門用語が必要最小限に抑えられている。
- 受講者がAIに任せる範囲と人が確認する範囲を分けて考えられる。
