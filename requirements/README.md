# VEXUMセミナー資料 要件定義

`requirements` 配下の要件定義は、**1つの統合文書で管理**する。

## 正本

- [`vexum-seminar-material-requirements.md`](./vexum-seminar-material-requirements.md) — VEXUMセミナー資料の全体方針・カリキュラム・全テーマ要件

## 管理方針

- テーマごとに別のMarkdownファイルを作成しない。
- 新しいテーマを追加する場合も、統合要件定義書の「カリキュラム構成」と「テーマ別要件」へ追記する。
- 内容の重複を避け、難易度・専門用語・評価・セキュリティ等の共通ルールは文書前半で一元管理する。
- 入社前セミナーはIT・AI初学者向けの入口とし、明示的な指示がない限り難しい技術詳細へ進まない。
- 専門用語は必要最小限にする。
- Theme番号と前提関係を常に一致させる。
- 呼称は**「セミナー資料」**に統一する。

旧テーマ別要件ファイルおよび旧統合ファイルは廃止する。
