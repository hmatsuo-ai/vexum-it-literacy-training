# VEXUM教科書 再構築要件定義

このフォルダは、VEXUM教科書をゼロから再構築するための**内容要件**を管理する。

旧教材のデザイン・ページ構成・配色・図版は原則として引き継がない。旧教材は「過去に何を扱っていたか」を確認する参照資料としてのみ使用し、新版の構成は各テーマの目的と到達目標から再設計する。

## 管理方針

- `00_repository-requirements.md`：教科書全体・セミナー目的の要件
- 各テーマ `.md`：テーマ別要件
- `_theme-template.md`：新しいテーマを追加するときの共通テンプレート

### IT基礎

- `03_it-pc-basics.md`：IT・PCの基礎

Theme 03では、**PC → ファイル → クラウド → Webサービス → AI**を一本の流れとして理解させる。

特に次を扱う。

- CPU / RAM / ストレージ / OS
- ファイル / フォルダ / 拡張子 / ファイルパス
- アップロード / ダウンロード
- ローカル / クラウド / 同期 / 共有
- ブラウザ / URL / クライアント / サーバー
- アカウント / ログイン / 認証 / 閲覧権限 / 編集権限
- AIがローカルファイルやクラウド情報を利用するまでの基本的なデータの流れ

IT専門家向けの講義にはせず、AI・クラウド・業務ツールを理解して使うための最低限の基礎に限定する。

### AI基礎

- `07_ai-overview.md`：AIとは何か・LLMの仕組み
- `08_ai-tools.md`：GPT / ChatGPT・Claudeを中心とした生成AIの主要ツールと共通する使い方
- `09_prompting.md`：言語化・要件整理・プロンプト
- `10_agents-and-vibe-coding.md`：AIエージェント・バイブコーディング
- `11_ai-security.md`：AI・情報セキュリティ

GPT / ChatGPTとClaudeは主要な二大ツールとして扱うが、VEXUMの通常業務で使う範囲ではできることの重なりが大きいことを前提にする。固定的な優劣や得意分野の暗記ではなく、その時点の機能・連携環境・使いやすさ・出力を見て選ぶ。

NotebookLMは「資料を中心に質問・要約・比較するAI活用」の具体例として短く紹介する。必須ツールとして習得させるのではなく、教科書1ページ以内・説明5分以内を目安とし、NotebookLM単体の操作テストは行わない。

AIの性能については、次の共通理解を扱う。

- 軽量・低推論の利用は速い傾向
- 高性能・高推論の利用は時間がかかる代わりに複雑な検討に向く傾向
- Web調査や外部ツール利用は通常の対話より時間がかかる
- 高性能なAIでも、自動的に外部情報を調査するとは限らない
- 渡した資料を読む場合は、回答の根拠を元資料へ戻って確認する
- MCP等を通じて外部ツール・データへ接続する場合は、接続先・権限・操作範囲を確認する

### 業務ツール

- `12_google-workspace-microsoft-365.md`：Google Workspace と Microsoft 365

Google WorkspaceとMicrosoft 365は別々の製品紹介にせず、**同じ業務を各環境でどう行うか**を比較して教える。

特に次を明確にする。

- Googleドキュメント ↔ Word
- Googleスプレッドシート ↔ Excel
- Googleスライド ↔ PowerPoint
- Google Drive ↔ OneDrive / SharePoint
- Gmail ↔ Outlook
- Google Meet ↔ Teams

比較軸は、保存場所、ローカル／クラウド、ファイル形式、共同編集、共有権限、互換性とする。

## 重要な原則

- PC・ファイル・クラウド等の基礎を飛ばさず、その延長としてAIを教える。
- セミナーではVEXUMとAI活用の面白さ・可能性を伝え、受講者の学習意欲を高める。
- 説教型・規範型のマナー研修を入れない。
- デザイン仕様と内容要件を混ぜない。
- 暗記ではなく、説明・操作・判断ができることを到達目標にする。
- 特定AI製品の比較・ランキングを教材の中心にしない。
- NotebookLMは資料ベースAI活用の一例としてのみ紹介し、製品機能の暗記対象にしない。
- モデル名、料金、UI、製品機能など変化が速い情報を本質的な学習目標にしない。
- Google WorkspaceとMicrosoft 365は、役割・保存・共有・ファイル形式の違いから比較する。
- 受講者のITリテラシー差を前提に、基礎用語を飛ばさない。
- セミナー目的から逆算し、必要なテーマだけを採用する。

**「社会人としての基本姿勢」「対面・クライアント対応マナー」はセミナー教材から分離する。** マナー、敬語、席次、名刺交換等は、必要な場合のみ契約・入社後のオンボーディングや個別業務ルールとして扱う。
