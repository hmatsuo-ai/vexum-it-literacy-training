# VEXUM教科書 要件定義

`requirements` 配下の要件定義は、**1つの統合文書で管理**する。

## 正本

- [`vexum-textbook-requirements.md`](./vexum-textbook-requirements.md) — VEXUM教科書の全体方針・カリキュラム・全テーマ要件

## 管理方針

- テーマごとに別のMarkdownファイルを作成しない。
- 新しいテーマを追加する場合も、統合要件定義書の「カリキュラム構成」と「テーマ別要件」へ追記する。
- 内容の重複を避け、難易度・専門用語・評価・セキュリティ等の共通ルールは文書前半で一元管理する。
- セミナーはIT・AI初学者向けの入口とし、明示的な指示がない限り難しい技術詳細へ進まない。
- 専門用語は必要最小限にする。

旧テーマ別要件ファイルおよびテーマ追加用テンプレートは、統合に伴い廃止する。
