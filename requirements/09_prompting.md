# Theme 09｜プロンプト

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 08の次

## 1. このテーマの目的

生成AIへの依頼を思いつきで投げるのではなく、**目的・前提・制約・期待する出力を整理して伝え、AIとのやり取りを改善できる状態**を作る。

プロンプトを「呪文」や「テンプレート暗記」として教えるのではなく、AIへ仕事を依頼するための要件整理として理解させる。

## 2. 対象者・前提知識

Theme 07「AIとは何か」、Theme 08「AIツールの全体像」を受講済み。

## 3. 到達目標

- 曖昧な依頼と具体的な依頼の違いを説明できる。
- 目的、背景、制約、出力形式を整理してAIへ伝えられる。
- RCCO等のフレームワークを補助として使える。
- 1回で完璧な回答を求めず、追加情報・修正指示・検証を繰り返せる。
- AI側に不足情報を質問させる使い方ができる。
- AI出力をそのまま採用せず、目的に合っているか確認できる。

## 4. 必須学習内容

### 良い依頼の基本構造

AIへ依頼するときは、最低限以下を整理する。

1. **目的**：何を達成したいか
2. **背景・前提**：AIが知らない状況や情報
3. **対象**：誰向けの成果物か
4. **制約**：してはいけないこと、条件、期限、文字数等
5. **出力**：どの形式で返してほしいか

### RCCO

RCCOは便利な整理方法の一つとして紹介する。

- Role：AIにどの役割で考えてほしいか
- Context：背景・状況・前提
- Constraints：守る条件
- Output：欲しい出力

RCCOという名前の暗記は目的にしない。

### AIとの反復

**依頼 → 出力を見る → 足りない点を見つける → 修正を指示する → 再確認する**

という流れを実演する。

### AIに質問させる

前提情報が不足している場合は、AIに勝手に推測させるのではなく、必要な質問を先に出させる方法も扱う。

## 5. 扱わない内容

- 長いプロンプトほど良いという考え方
- RCCOを唯一の正解として暗記すること
- 「絶対に精度が上がる魔法の一文」
- 数十個のプロンプトテンプレート暗記
- モデル固有の細かなテクニックを基礎原則より優先すること

## 6. 推奨学習構成

**雑な依頼を実演 → 出力の問題を見る → 必要情報を整理 → 改善したプロンプト → 出力改善 → さらに修正**

最初から完成されたプロンプトを見せるより、改善前後の差を体験させる。

## 7. 実務ケース

最初に、

> 「この資料をまとめて」

だけをAIへ依頼した例を見せる。

その後、
- 誰向けか
- 何のための要約か
- 重要項目は何か
- どの形式でほしいか

を追加し、出力がどう変わるか比較する。

## 8. 演習

受講者に短い業務課題を与え、

**初回プロンプト → AI出力 → 問題点 → 改善プロンプト → 改善後の出力**

を実際に体験させる。

## 9. 理解度確認

悪いプロンプトを提示し、

1. 何が不足しているか
2. AIに何を追加で伝えるべきか
3. どのように改善するか

を説明させる。

## 10. 更新対象情報

モデルごとの入力上限、ファイル対応、ツール呼び出し等。

プロンプトの基本原則は特定製品に依存させない。

## 12. 完成条件

- 受講者がプロンプトを「AIへの仕事の依頼」として理解している。
- 目的・背景・制約・出力を整理して伝えられる。
- AIとの反復改善を実行できる。
- RCCOの暗記研修になっていない。
- 後続のChatGPT・Claude・Gemini等の実践へ自然につながる。
