# Theme 09｜AIに仕事を伝える｜言語化・要件整理・プロンプト

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 08の次

## 1. このテーマの目的

生成AI時代に重要なのは、長い「魔法のプロンプト」を覚えることではない。

**頭の中の曖昧なイメージを、AIが作業できる具体的な要件へ変換する力**を身につける。

Theme 09では実装まで行わず、Theme 10でAIに作らせる家計簿Webアプリの要件を完成させるところまでを担当する。

## 2. 到達目標

- 曖昧な要望を、目的・ユーザー・利用場面・必要条件・制約・完成条件へ分解できる。
- AIに不足情報を質問させ、対話しながら要件を具体化できる。
- プロンプトを「呪文」ではなく、整理した要件をAIへ渡す手段として理解する。
- 1回の指示で完成を狙わず、試作後に評価・修正する前提で要件を作れる。
- Theme 10で実装に使える家計簿Webアプリの簡単な要件書を作成できる。

## 3. 必須学習内容

### 3.1 AI時代に重要な「言語化」

AIは曖昧な依頼からでも何かを生成できるが、要求が曖昧なままだと、**それらしいが本当に欲しかったものとは違う成果物**になりやすい。

最低限、次を考える。

1. **目的**：何を実現したいか
2. **ユーザー**：誰が使うか
3. **利用場面**：いつ・どこで・どう使うか
4. **必要な機能・情報**：何ができればよいか
5. **優先順位**：何が最も重要か
6. **制約**：してはいけないこと、環境、形式等
7. **完成条件**：どうなれば「できた」と言えるか

### 3.2 AIに質問させて要件を詰める

最初から人が完璧に言語化できるとは限らない。

そこでAIへ、

> この依頼を実行するために不足している情報を、重要度順に質問してください。

のように依頼し、回答しながら要件を整理する。

AIに質問させれば人が考えなくてよいわけではない。目的・利用者・優先順位・使いやすさの最終判断は人が行う。

### 3.3 「動く」と「使いやすい」は違う

家計簿アプリを例に、

- 入力項目が多すぎないか
- スマホから入力しやすいか
- 金額の入力ミスが起きにくいか
- よく使うカテゴリを選びやすいか
- 月の支出状況がすぐ分かるか

など、ユーザー視点で完成条件を考える。

### 3.4 プロンプトの基本

プロンプトは要件をAIへ伝える手段として扱う。

基本要素は、

- 目的
- 背景・前提
- 対象ユーザー
- 入力情報
- 必要条件
- 制約
- 出力形式
- 完成条件

程度でよい。

RCCO等のフレームワークは紹介してもよいが、暗記対象にはしない。

## 4. メインワーク｜家計簿Webアプリの要件を作る

Theme 10で実際にAIへ実装させるため、Theme 09では要件だけを作る。

最初の依頼は、

> 家計簿Webアプリを作りたい。

程度の曖昧な状態から始める。

AIにも不足情報を質問させながら、最低限次まで具体化する。

### 要件例

- 主な利用者：自分
- 利用端末：スマートフォン中心
- 目的：支出をすぐ記録し、月の使いすぎを把握する
- 保存先：Googleスプレッドシート
- 必須入力：日付、金額、カテゴリ、メモ
- 必要画面：入力画面、支出一覧、月合計
- 重視すること：入力の速さ、迷わないUI
- 不要なもの：複雑な会計機能、多人数共有、高度な分析
- 完成条件：スマホから短時間で入力でき、保存結果と月合計を確認できる

受講者ごとに細部が異なってもよい。

### Theme 09の成果物

**Theme 10へそのまま渡せる1枚程度の要件書**を完成させる。

Theme 09ではコード生成・GAS設定・デプロイは行わない。

## 5. 補助ワーク｜画像を言語化する

時間がある場合のみ、画像生成でも同じ考え方が使えることを短く示す。

「かっこいい画像」ではなく、用途、対象者、主役、構図、雰囲気、背景、入れてほしくない要素等へ分解する。

メインは家計簿アプリ要件とし、画像生成は補助に留める。

## 6. 扱わない内容

- 長いプロンプトほど良いという考え方
- プロンプトテンプレートの大量暗記
- 「絶対に精度が上がる魔法の一文」
- AIが質問してくれるので人は要件を考えなくてよいという説明
- Theme 09内でのアプリ実装
- GAS・HTML・JavaScript等の技術説明

## 7. 推奨学習構成

**曖昧な要望 → 目的・ユーザーを考える → AIに不足情報を質問させる → 要件を整理 → 完成条件を決める → Theme 10用の要件書を完成**

## 8. 理解度確認

次を確認する。

1. なぜAI時代に言語化能力が重要なのか
2. 目的・ユーザー・利用場面を先に考える理由
3. AIに不足情報を質問させる利点
4. 「動く」と「使いやすい」の違い
5. Theme 10で実装できる程度まで要件を具体化できているか
