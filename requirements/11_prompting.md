# Theme 11｜プロンプト

- 区分：CORE
- 想定受講段階：AI基礎後

## 1. このテーマの目的

生成AIへの依頼を思いつきで投げるのではなく、目的・前提・制約・期待する出力を整理して伝え、出力を改善できるようにする。

## 2. 対象者・前提知識

Theme 09を受講済み。

## 3. 到達目標

- 曖昧な依頼と具体的な依頼の違いを説明できる。
- Role、Context、Constraints、Output（RCCO）等を使って要件を整理できる。
- 1回で完璧な回答を求めず、追加情報・修正指示・検証を繰り返せる。
- AIが知らない前提資料を必要に応じて与えられる。

## 4. 必須学習内容

- プロンプトは「質問文」ではなくAIへの作業指示であること
- 目的、背景、対象読者、入力資料、制約、出力形式
- RCCO：Role / Context / Constraints / Output
- 良い例・悪い例の比較
- 追加質問をさせる方法
- 長文資料・ファイルを前提として渡す考え方
- 出力を評価し、修正指示を出す反復
- 事実確認が必要な箇所をAI自身に明示させる方法

## 5. 扱わない内容

- RCCOを唯一の正解として暗記させること
- 長いプロンプトほど良いという考え方
- 「魔法の一文」の収集

## 6. 推奨学習構成

曖昧な依頼 → 必要情報の分解 → RCCO → 実務プロンプト → 出力評価 → 改善

## 7. 実務ケース

「顧客向け報告メールを作って」だけでは情報が足りない例から、目的・状況・事実・禁止事項・出力条件を追加する。

## 8. 演習

受講者が実際の業務タスクを1つ選び、初稿プロンプト → AI出力 → 改善プロンプトの3段階を記録する。

## 9. 理解度確認

提示された悪いプロンプトの不足情報を指摘し、改善版を作らせる。

## 10. 更新対象情報

モデルごとの入力上限・ファイル対応・ツール呼び出し等。プロンプト原則そのものは製品依存にしない。

## 11. 他テーマとの依存関係

- 前提：Theme 09
- 次に学ぶ候補：Theme 12、14、15、16、17

## 12. 完成条件

受講者がRCCOの用語を見ずにでも、目的・背景・制約・出力を含む実務指示を組み立てられる。
