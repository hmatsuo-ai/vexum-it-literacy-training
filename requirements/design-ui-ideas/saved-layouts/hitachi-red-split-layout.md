# Saved Layout｜Hitachi風 MONOCHROME SPLIT STORY

ユーザー共有スクリーンショットをもとに、VEXUM Academyで再利用するレイアウトパターンとして保存する。

## 核となる構成

- 画面全体を覆う背景写真
- 背景写真の上に高濃度の単色オーバーレイ
- 左55〜60%：ストーリー本文
- 右40〜45%：巨大コピー
- 右下：短いCTA＋横線＋円形アウトライン矢印
- 余白を大きく取り、カードや装飾を置きすぎない

## 左カラム

- 左上に小さな導入ラベル
- その下に複数段落の説明
- 一文ごとに改行を多く取り、文章をリズムとして見せる
- 段落間を広く取る
- 白文字・太めのゴシック

## 右カラム

- 右下寄せ
- 3〜4行の巨大コピー
- 本文の2〜3倍のサイズ
- 文法より視覚的なリズムを優先して改行

VEXUM例：

> AIで、
> 仕事の未来を、
> ここから

または：

> 考える力を、
> つくる力へ。

## CTA

- セクション右下
- テキスト＋横線＋円形アウトライン
- 円内に右矢印
- ホバーで円を少し拡大し、矢印を右へスライド

## 色設計

1セクションをほぼ単色で支配する。

VEXUM候補：
- Deep Red：Mission / Company
- Electric Blue：AI / LLM
- Deep Navy：IT基礎
- Violet：Build / Vibe Coding
- Black / White：章間のリセット

背景写真は見せることが目的ではなく、単色の下に沈ませて文脈だけを残す。

## 余白・文字サイズ目安

- 左右padding：5〜7vw
- 上下padding：5〜8vw
- 段落間：2〜4rem
- 本文：18〜24px
- 本文line-height：1.8〜2.0
- 巨大コピー：clamp(48px, 6vw, 90px)
- font-weight：600〜800

## モーション

- 背景写真：弱いパララックス
- 左本文：段落単位でfade + translateY
- 右コピー：1行ずつ遅延表示
- CTA：円拡大＋矢印移動
- 次セクション：単色面がワイプして切り替わる

## Mobile

- 2カラムを縦1列へ
- 説明 → 巨大コピー → CTA の順
- 巨大コピー：36〜52px
- 背景画像は中央寄せでトリミング

## 使用ルール

- 左右で役割を完全に分ける
- 巨大コピーは説明ではなく感情を動かすために使う
- 背景写真・UI・CTAを同じ色世界で統一する
- 1画面にカードやアイコンを大量配置しない
- 連続使用せず、Chapter Introや重要な転換点に限定する
