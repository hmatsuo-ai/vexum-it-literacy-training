# Theme 02｜現在のVEXUM・働き方

- 区分：SEMINAR-CORE
- 想定受講段階：導入

## 1. このテーマの目的

VEXUMの過去を詳しく学ぶのではなく、**現在のVEXUMが何を目指し、どのように顧客へ価値を提供し、受講者がセミナー後にどのような流れで成長して常駐へ進むのか**を理解する。

沿革は現在を理解するための最低限の背景に限定し、歴史説明そのものを目的にしない。

## 2. 対象者・前提知識

Theme 01を受講済みの新規受講者。

## 3. 到達目標

- VEXUMが**2025年7月に設立された会社**であることを知っている。
- 現在のVEXUMが、AI活用・顧客支援・人材育成をどのようにつなげているかを説明できる。
- セミナー終了後から常駐開始までの流れを順番に説明できる。
- 常駐開始後も、いきなり一人で業務を任されるのではなく、アドバイザーから働き方を学びながら徐々に実務へ慣れていくことを理解する。
- VEXUMで働くことで、どのようなスキル・経験を身につけられるかを具体的な成長ステップで説明できる。

## 4. 必須学習内容

- **設立：2025年7月**
- 現在のVEXUMが目指していること
- 現在の主な顧客支援の考え方
- AI活用と人の役割を組み合わせる考え方
- 現在のVEXUMにおける人材育成の位置づけ

### セミナー終了後から常駐開始までの流れ

1. **セミナー終了後にテスト**
   - セミナーで扱った内容の理解度を確認する。
2. **雇用契約**
   - テスト通過後、雇用契約へ進む。
3. **技術研修（3時間）**
   - 実務に進むために必要な技術の基礎を学ぶ。
4. **NEXUS研修（Gate 10まで）**
   - 課題を進めながら、必要な知識・技術・問題解決力を身につける。
5. **常駐開始**
   - 常駐開始後の初期段階では、**アドバイザーが3回付き添う**。
   - アドバイザーから常駐先での働き方を学びながら、徐々に現場へ慣れていく。
   - 最初からすべてを一人で担当するのではなく、段階的に**システム開発**や**顧客折衝**へ関わる範囲を広げていく。

### 受講者のキャリアとの接続

「身につけられるスキル・経験」を抽象的に並べるのではなく、VEXUMで経験する成長の流れとして具体的に見せる。

**AIを使う → 業務を理解する → 課題を発見する → 改善案を考える → 実装する → 顧客に価値を出す**

この流れを、受講者が将来たどるキャリアの基本ステップとして説明する。

- **AIを使う**：生成AIや業務ツールを使い、作業や情報整理を効率化する。
- **業務を理解する**：顧客がどのような仕事をしているか、現場の流れや前提を理解する。
- **課題を発見する**：非効率、属人化、手作業、情報分散など、改善できるポイントを見つける。
- **改善案を考える**：AI・システム・業務フローのどこを変えると価値が出るかを考える。
- **実装する**：必要に応じてシステムや仕組みを作り、現場で使える形にする。
- **顧客に価値を出す**：導入して終わりではなく、実際に使われ、業務が改善された状態までつなげる。

Theme 2では、受講者が「この会社に入ると最終的に何ができるようになるのか」を具体的にイメージできることを重視する。

### 受講者が今後身につけられるスキル・経験

- AIを業務で使う
- 顧客業務を理解する
- 課題を発見・整理する
- 改善案を考える
- 必要に応じてシステムや仕組みを作る
- 顧客と会話し、要望や課題を整理する
- 顧客の現場で使える状態まで改善する
- 実際の常駐現場で成果を出す

## 6. 推奨学習構成

**2025年7月に設立 → 現在のVEXUM → 現在の仕事 → セミナー後の成長フロー → 常駐開始後の働き方 → 自分がどう成長できるか**

設立年月は1行程度で扱い、時間の大半は「今のVEXUM」と「受講者がこれからどう成長していくか」の説明に使う。

セミナー後の流れは、以下を一続きのロードマップとして視覚的に理解できる構成にする。

**セミナー → テスト → 雇用契約 → 技術研修（3時間） → NEXUS Gate 10 → 常駐開始 → アドバイザー付き添い3回 → 徐々にシステム開発・顧客折衝へ**

その後に、キャリアの成長イメージとして以下を示す。

**AIを使う → 業務を理解する → 課題を発見する → 改善案を考える → 実装する → 顧客に価値を出す**

## 7. 実務ケース

VEXUMが顧客の定型作業をAIで短縮した場合、その後に人がどのような価値を提供できるかを考える。

単なる自動化ではなく、業務理解・課題発見・改善・開発・顧客との対話・運用までつなげることを考えさせる。

## 8. 演習

「今できること／技術研修・NEXUSで身につけたいこと／常駐後にできるようになりたいこと」を3つに分けて整理する。

そのうえで、セミナーから常駐までのどの段階で、何を身につける必要があるかを考える。

さらに、**AIを使う → 業務を理解する → 課題を発見する → 改善案を考える → 実装する → 顧客に価値を出す**の6段階のうち、自分が現在どこにいて、次に何を伸ばしたいかを考える。

## 9. 理解度確認

会社史は出題しない。
