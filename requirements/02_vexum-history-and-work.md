# Theme 02｜セミナー後の自分のロードマップ

- 区分：SEMINAR-CORE
- 想定受講段階：Theme 01の次

## 1. このテーマの目的

Theme 01で「VEXUMは何をする会社か」を理解した後、Theme 02では**受講者自身が、セミナー後にどのような順番で学び、実務へ進んでいくのか**を理解する。

会社説明やVEXUMの事業モデルは繰り返さない。

終了時に、受講者が「今どこにいて、次に何をするのか」を自分の言葉で説明できる状態を目指す。

## 2. 対象者・前提知識

Theme 01を受講済みの新規受講者。

## 3. 到達目標

- セミナー終了後から常駐開始までの流れを順番に説明できる。
- 各段階が何のためにあるのかを大まかに説明できる。
- 常駐開始後も、いきなりすべてを一人で担当するわけではなく、段階的に実務へ慣れていくことを理解する。
- 自分が今後どのような力を身につけるのかをイメージできる。
- Theme 03以降のIT・AI学習が、実務のどこにつながるかを理解する。

## 4. 必須学習内容

### 4.1 セミナー後の基本ロードマップ

現行の正式運用を確認したうえで、以下を一続きの図で示す。

**セミナー → 理解度確認・テスト → 雇用契約 → 技術研修 → NEXUS → 常駐開始 → OJT・実務**

制度名・回数・Gate等、変更されやすい情報は教材公開前に最新運用を確認する。

### 4.2 各段階の意味

#### セミナー

- VEXUMと仕事の全体像を理解する
- IT・AIの入口を知る
- 次の研修へ進むための基礎理解を確認する

#### 理解度確認・テスト

- 暗記量ではなく、説明・判断・ワーク遂行ができるかを見る

#### 雇用契約

- 正式な手続きを経て、次の研修・業務へ進む

#### 技術研修

- セミナーより実践的なIT・開発・セキュリティ等を学ぶ
- セミナーに高度な技術を詰め込まない理由をここで明確にする

#### NEXUS

- 課題を通して、自分で考え、作り、修正する力を伸ばす
- Gate等の細かな仕様は最新運用を参照する

#### 常駐・OJT

- 顧客環境で実際の業務を理解する
- 必要に応じてアドバイザー等の支援を受けながら段階的に実務へ入る
- 最初から一人で全責任を負う前提にはしない

### 4.3 成長イメージ

制度説明だけで終わらせず、「何ができるようになるか」を次の流れで示す。

**AI・ITを使う**
→ **業務を理解する**
→ **課題を見つける**
→ **改善案を考える**
→ **仕組みを導入・実装する**
→ **実際に使ってもらう**
→ **結果を確認して改善する**

Theme 01ではこの仕事そのものを説明し、Theme 02では**自分がこの仕事をできるようになるまでの学習順**として見せる。

### 4.4 この後の教科書との接続

- Theme 03：PC・ファイル・クラウド等のIT基礎
- Theme 07：LLMとは何か
- Theme 08：実際の生成AIアプリの使い方
- Theme 09：要件を言語化してAIへ伝える
- Theme 10：AIに実装させ、触って改善する
- Theme 11：安全にAIを使う

受講者に「なぜこの順番で学ぶのか」を理解させる。

## 5. 扱わない内容

- VEXUMの事業説明の繰り返し（Theme 01で扱う）
- 一般的なITコンサルとの比較（Theme 01で扱う）
- 顧客課題の詳細な解決プロセス（Theme 01で扱う）
- NEXUSの全Gateや課題内容の説明
- 技術研修の詳細カリキュラム
- 顧客ごとの常駐ルール
- 過去の制度・フローの履歴
- 将来予定を確定事項のように記載すること

## 6. 推奨学習構成

**いま：セミナー → 次：テスト・契約 → 技術研修 → NEXUS → 常駐・OJT → 将来できるようになる仕事**

ロードマップは1枚の図を中心に説明し、会社説明へ戻らない。

## 7. 演習

受講者に、次の3点を短く書かせる。

1. 自分はいまどの段階にいるか
2. 次に進む段階は何か
3. 常駐までに身につけたい力は何か

## 8. 理解度確認

次を確認する。

1. セミナー後から常駐までの大まかな順序
2. 技術研修とNEXUSは何のためにあるか
3. なぜセミナーだけで実務スキルを完成させないのか
4. 常駐開始後はどのように実務へ慣れていくか
5. Theme 03以降の学習が実務の何につながるか

## 9. 更新対象情報

- テスト・契約・技術研修・NEXUS・常駐開始までの正式フロー
- NEXUSのGate要件
- アドバイザー・OJTの正式運用
- 研修名称・所要時間

変更されやすい数字・回数は固定知識として暗記させない。
