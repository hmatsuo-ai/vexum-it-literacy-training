# Theme 20｜Microsoft 365

- 区分：CORE
- 想定受講段階：業務ツール基礎

## 1. このテーマの目的

Microsoft 365を企業で広く利用されるクラウド業務基盤として理解し、Google Workspaceとの共通点・違いを把握して、顧客環境に応じて適応できるようにする。

## 2. 対象者・前提知識

IT初学者を含む全受講者。Theme 16の前後どちらでも学習可能。

## 3. 到達目標

- Microsoft 365とWindows、Officeアプリの関係を大まかに説明できる。
- Outlook、OneDrive、SharePoint、Teams、Word、Excel、PowerPointの役割を区別できる。
- ローカル保存とクラウド保存、個人領域と組織共有領域を区別できる。
- Google Workspaceとの代表的な対応関係を説明できる。
- 顧客がMicrosoft環境の場合にGoogle前提で操作しない判断ができる。

## 4. 必須学習内容

- Microsoft 365とは何か
- 組織アカウントと個人Microsoftアカウント
- Outlook、Teams、OneDrive、SharePoint、Word、Excel、PowerPoint
- OneDriveとSharePointの役割の違いを初学者向けに説明すること
- デスクトップアプリとブラウザ版・クラウドファイルの関係
- 共有リンク・権限・組織外共有
- Google Workspaceとの代表対応：Gmail／Outlook、Drive／OneDrive・SharePoint、Docs／Word、Sheets／Excel、Slides／PowerPoint、Meet／Teams等
- Copilot等のAI支援は契約・設定を確認して利用すること

## 5. 扱わない内容

- Excel関数やOffice操作の網羅
- ライセンス名・価格の暗記
- Google Workspaceと完全に同じだと説明すること

## 6. 推奨学習構成

Microsoft 365とは → アカウント → 各アプリ → ファイル保存・共有 → Googleとの比較 → AI → 演習

## 7. 実務ケース

顧客からSharePoint上の資料URLを受け取ったとき、Google Driveへ勝手にコピーせず、権限・保存場所・編集方法を確認する。

## 8. 演習

同じ「チームで資料を共同編集する」業務をGoogle WorkspaceとMicrosoft 365の両方で構成し、どのサービスが何に対応するか整理する。

## 9. 理解度確認

OneDrive／SharePoint／ローカルの違いや、Google環境との置き換えをケースで説明させる。

## 10. 更新対象情報

Microsoft 365プラン、Teams・SharePoint・OneDrive UI、Copilot、管理者設定、共有制御。

## 11. 他テーマとの依存関係

- 前提：Theme 13推奨
- 次に学ぶ候補：Theme 21、24

## 12. 完成条件

受講者がGoogle WorkspaceとMicrosoft 365を混同せず、顧客の利用環境に合わせて基本的なファイル・共有行動を選べる。
