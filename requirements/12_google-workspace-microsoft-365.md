# Theme 12｜Google Workspace と Microsoft 365

- 区分：SEMINAR-CORE / POST-HIRE
- 想定受講段階：PC・ファイル・クラウド基礎の後

## 1. このテーマの目的

Google WorkspaceとMicrosoft 365を別々の製品紹介として覚えるのではなく、**「文章を作る」「表計算をする」「資料を作る」「メールを送る」「ファイルを保存・共有する」といった同じ業務を、それぞれの環境では何を使って行うのか**を理解する。

特に、WordとGoogleドキュメント、ExcelとGoogleスプレッドシート、PowerPointとGoogleスライド、Google DriveとOneDrive／SharePointの違いを、IT初学者でも説明できる状態を目指す。

## 2. 対象者・前提知識

IT初学者を含む全受講者。

事前に次を理解していることが望ましい。

- ファイルとフォルダ
- ローカル保存とクラウド保存
- アカウント
- アップロードとダウンロード
- 共有権限

## 3. 到達目標

- Google WorkspaceとMicrosoft 365が、どちらも組織で使う業務ツール群であることを説明できる。
- 同じ業務について、Google側とMicrosoft側の代表的なツールを対応付けられる。
- WordとGoogleドキュメントの保存方法・ファイル形式・共同編集の違いを説明できる。
- ExcelとGoogleスプレッドシート、PowerPointとGoogleスライドについても同様の違いを説明できる。
- Google Drive、OneDrive、SharePointの役割を混同しない。
- 顧客や会社が指定した環境を優先し、勝手に別サービスへコピーしない判断ができる。

## 4. まず理解する対応関係

| やりたいこと | Google Workspace | Microsoft 365 |
|---|---|---|
| メール | Gmail | Outlook |
| 予定管理 | Google Calendar | Outlook Calendar |
| オンライン会議 | Google Meet | Microsoft Teams |
| 文書作成 | Googleドキュメント | Microsoft Word |
| 表計算 | Googleスプレッドシート | Microsoft Excel |
| プレゼン資料 | Googleスライド | Microsoft PowerPoint |
| 個人・自分中心のクラウド保存 | Google Drive のマイドライブ | OneDrive |
| 組織・チーム共有 | Google Drive の共有ドライブ等 | SharePoint / Teams |

この表は「完全に同じ機能」という意味ではなく、**業務上の大まかな役割が近いもの**として扱う。

## 5. Word と Googleドキュメントの違い

### 共通点

どちらも文章を作成・編集するためのツール。

- レポート
- 議事録
- 手順書
- 提案書の文章
- 社内文書

などを作成できる。

### Googleドキュメント

- Google Drive上で扱うクラウド中心の文書。
- 基本的にGoogleアカウントとDrive上の保存場所を意識して使う。
- URLで同じ文書を共有し、複数人で同時編集しやすい。
- 編集内容は自動保存される。
- Google独自の文書として扱い、必要に応じてWord形式やPDFへ書き出せる。
- オフライン利用も可能な場合があるが、事前設定や利用環境に依存する。

### Microsoft Word

- `.docx` などのファイルとして扱う考え方が強い。
- PCのローカル、USB、OneDrive、SharePointなど複数の保存場所を選べる。
- デスクトップアプリでもブラウザでも利用できる。
- OneDriveやSharePointへ保存すれば共同編集もできる。
- ローカルだけに保存した場合、そのPC以外からはそのままでは利用できない。

### 初心者が最も注意する違い

**Googleドキュメントは「Drive上の同じ文書をみんなで開く」感覚が中心。**

**Wordは「文書ファイルをどこに保存しているか」をより意識する必要がある。**

Wordを使っていてもOneDriveやSharePointへ保存していればクラウド共同編集になるため、単純に「Word＝ローカル、Docs＝クラウド」と覚えない。

## 6. Excel と Googleスプレッドシートの違い

### 共通点

どちらも表形式で情報を管理し、計算・集計・グラフ作成等を行うツール。

### Googleスプレッドシート

- Google Drive上での共同編集を前提に使いやすい。
- URL共有と権限設定で複数人が同時編集しやすい。
- 自動保存される。
- Google独自形式で管理し、必要に応じてExcel形式等へ書き出す。

### Microsoft Excel

- `.xlsx` 等のファイルとして扱える。
- PCローカルでもOneDrive／SharePoint上でも使える。
- 高度な表計算、データ処理、既存の業務ファイルなどで広く使われる。
- クラウドへ保存すれば共同編集できるが、ローカルファイルをメール添付で回す運用も存在する。

### 注意点

GoogleスプレッドシートとExcelは多くの内容を相互変換できるが、**関数、書式、マクロ、外部接続、高度な機能等が完全に同じとは限らない。**

顧客から渡されたExcelファイルを、理由なくGoogleスプレッドシートへ変換しない。

## 7. PowerPoint と Googleスライドの違い

### 共通点

どちらもプレゼンテーション資料を作るツール。

### Googleスライド

- Drive上で共同編集しやすい。
- URL共有、自動保存が中心。
- PowerPoint形式やPDFへ書き出せる。

### Microsoft PowerPoint

- `.pptx` ファイルとしてローカル・OneDrive・SharePoint等へ保存できる。
- デスクトップアプリで高度なレイアウト、アニメーション等を扱える。
- クラウド保存時は共同編集もできる。

### 注意点

PowerPointとGoogleスライドの間で変換すると、フォント、配置、アニメーション、図形等が崩れる場合がある。

顧客提出物では、相手が指定する形式と、最終表示を必ず確認する。

## 8. Google Drive、OneDrive、SharePointの違い

ここは特に混同しやすいため、保存先の考え方から説明する。

### Google Drive

Google Workspaceでファイルを保存・共有する中心的な場所。

- 自分中心の領域
- 組織やチームで共有する領域

を分けて考える。

### OneDrive

Microsoft 365で、**基本的に個人を起点として仕事用ファイルを保存するクラウド領域**として理解する。

「自分の作業ファイルをクラウドに置く」イメージに近い。

### SharePoint

Microsoft 365で、**組織・部署・プロジェクト等のチーム単位で情報やファイルを共有する基盤**として理解する。

Teamsのチーム／チャネルで共有されるファイルがSharePoint側に保存されるケースもあるため、「Teamsの中にだけファイルが存在する」と考えない。

### 初心者向けの整理

- Google環境：まずDriveのどこにあるか確認
- Microsoft環境：自分中心ならOneDrive、チーム共有ならSharePointの可能性を確認

ただし、組織ごとに運用ルールが異なるため、保存場所を名前だけで決めつけない。

## 9. ローカルとクラウドを両環境で比較する

### ローカル保存

自分のPC内に保存されている状態。

- そのPCでは開ける
- 他端末からそのままでは開けない
- 共有するには別の手段が必要
- PC故障や紛失の影響を受ける可能性がある

### クラウド保存

Google Drive、OneDrive、SharePoint等へ保存されている状態。

- 権限があれば別端末から開ける
- URL共有や共同編集ができる
- 誰に何の権限があるか確認が必要

重要なのは、**WordやExcelを使っているか、DocsやSheetsを使っているかだけでは保存場所は判断できない**ことである。

## 10. ファイル形式の違い

初学者には次を理解させる。

- Word：`.docx`
- Excel：`.xlsx`
- PowerPoint：`.pptx`
- PDF：`.pdf`

Googleドキュメント、スプレッドシート、スライドはDrive上のGoogle独自形式として扱われ、必要に応じてMicrosoft形式やPDF等へ変換・出力できる。

拡張子だけを変更してファイル形式を変えようとしない。

## 11. アカウントの違い

同じブラウザで複数アカウントへログインしていると、

- 個人Googleアカウント
- 会社Google Workspaceアカウント
- 個人Microsoftアカウント
- 会社Microsoft 365アカウント

を取り違える可能性がある。

ファイルが開けない場合は、まず「どのアカウントで開いているか」を確認する。

## 12. 共有権限

両環境とも、保存されているだけでは相手が開けるとは限らない。

確認項目：

1. 誰に共有するか
2. 閲覧だけか、編集も許可するか
3. 組織外共有が許可されているか
4. 正しいアカウントへ権限を付けたか
5. 相手が実際に開けるか

## 14. 実務ケース

### ケース1：Wordファイルを受け取った

顧客から `.docx` が送られてきた。

確認すること：

- Word形式のまま編集すべきか
- 保存先はどこか
- Google形式へ変換してよいか
- 最終提出形式は何か

### ケース2：共有URLが開けない

まず、

- GoogleかMicrosoftか
- どのアカウントでログインしているか
- 権限が付与されているか

を確認する。

### ケース3：チームで共同編集する

Google環境ならDrive上、Microsoft環境ならOneDrive／SharePoint上等、組織が指定するクラウド保存先を使い、同じファイルを共同編集する。

## 15. 演習

同じ業務をGoogle環境とMicrosoft環境で対応付ける。

例：

1. 文書を作成する
2. チームで共有する
3. 閲覧権限を設定する
4. PDFにして提出する

それぞれについて、使用するツール、保存場所、ファイル形式、共有方法を整理する。
