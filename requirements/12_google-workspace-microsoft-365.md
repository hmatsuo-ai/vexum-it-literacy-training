# Theme 12｜Google Workspace と Microsoft 365

- 区分：POST-HIRE / REFERENCE
- 想定受講段階：Theme 03で対応表を見た後、契約・入社後に必要に応じて学ぶ

## 1. このテーマの目的

Google WorkspaceとMicrosoft 365を別々の製品カタログとして覚えるのではなく、**同じ業務をそれぞれの環境では何を使って行い、保存・共有・ファイル形式がどう違うのか**を理解する。

入社前セミナーではTheme 03で5〜10分の対応表だけ扱う。本テーマの詳細比較はセミナー必須範囲にしない。

特に、

- Word と Googleドキュメント
- Excel と Googleスプレッドシート
- PowerPoint と Googleスライド
- Google Drive と OneDrive / SharePoint

を、実務で迷わない程度まで整理する。

## 3. 代表的な対応関係

| やりたいこと | Google Workspace | Microsoft 365 |
| --- | --- | --- |
| メール | Gmail | Outlook |
| 予定管理 | Google Calendar | Outlook Calendar |
| オンライン会議 | Google Meet | Teams |
| 文書作成 | Googleドキュメント | Word |
| 表計算 | Googleスプレッドシート | Excel |
| プレゼン | Googleスライド | PowerPoint |
| 自分中心のクラウド保存 | Google Driveのマイドライブ | OneDrive |
| 組織・チーム共有 | Google Driveの共有ドライブ等 | SharePoint / Teams |

完全に同じ機能という意味ではなく、**業務上の役割が近いもの**として理解する。

## 4. Word と Googleドキュメント

### 共通点

どちらも文章を作るためのツール。

### Googleドキュメント

- Google Drive上で扱うクラウド中心の文書
- URLで同じ文書を共有し、共同編集しやすい
- 自動保存が中心
- 必要に応じてWord形式やPDFへ書き出せる

### Word

- `.docx` 等のファイルとして扱える
- PCローカル、OneDrive、SharePoint等、複数の保存場所を選べる
- デスクトップアプリとブラウザ版がある
- OneDrive / SharePointへ保存すれば共同編集もできる

### 最も重要な注意

**Word＝ローカル、Docs＝クラウド**と単純化しない。

Wordでもクラウド保存できるため、重要なのは「何のアプリか」だけでなく、**ファイルがどこに保存されているか**である。

## 5. Excel と Googleスプレッドシート

### Googleスプレッドシート

- Drive上で共同編集しやすい
- URL共有と自動保存が中心
- 必要に応じてExcel形式等へ書き出せる

### Excel

- `.xlsx` 等のファイルとして扱える
- ローカルでもOneDrive / SharePoint上でも利用できる
- 既存の業務ファイル、高度な表計算・データ処理等で広く使われる

### 注意

相互変換できる場合でも、関数、書式、マクロ、外部接続等が完全に同じとは限らない。

顧客から受け取ったExcelファイルを理由なくGoogle形式へ変換しない。

## 6. PowerPoint と Googleスライド

### Googleスライド

- Drive上で共同編集しやすい
- URL共有・自動保存が中心
- PowerPoint形式やPDFへ書き出せる

### PowerPoint

- `.pptx` としてローカル・OneDrive・SharePoint等へ保存できる
- デスクトップアプリでは高度なレイアウト・アニメーション等も扱える
- クラウド保存時は共同編集できる

### 注意

PowerPointとGoogleスライド間の変換では、フォント、配置、アニメーション、図形等が崩れる場合がある。

顧客提出物では最終表示を確認する。

## 7. Drive、OneDrive、SharePoint

### Google Drive

Google環境でファイルを保存・共有する中心的な場所。自分中心の領域と、組織・チームで共有する領域を分けて考える。

### OneDrive

Microsoft環境で、基本的に**個人を起点として仕事用ファイルを保存するクラウド領域**として理解する。

### SharePoint

Microsoft環境で、**組織・部署・プロジェクト等のチーム単位で情報やファイルを共有する基盤**として理解する。

Teams上の共有ファイルがSharePoint側に保存されるケースもあるため、「Teamsの中だけにある」と考えない。

## 8. ローカルとクラウド

アプリ名だけで保存場所を判断しない。

### ローカル

- 自分のPC内にある
- 他端末からそのままでは開けない
- 共有には別手段が必要

### クラウド

- 権限があれば別端末から開ける
- URL共有・共同編集ができる
- 誰が何の権限を持つか確認が必要

## 9. ファイル形式

代表例だけ扱う。

- Word：`.docx`
- Excel：`.xlsx`
- PowerPoint：`.pptx`
- PDF：`.pdf`

拡張子だけを変更してファイル形式を変えようとしない。

Googleドキュメント、スプレッドシート、スライドはDrive上のGoogle形式として扱われ、必要に応じてMicrosoft形式やPDF等へ出力できる。

## 10. アカウントと共有権限

同じブラウザで複数アカウントへログインしていると、個人アカウントと会社アカウントを取り違えることがある。

ファイルが開けないときは、まず、

1. Google環境かMicrosoft環境か
2. どのアカウントで開いているか
3. 閲覧・編集権限が付いているか
4. 組織外共有が許可されているか

を確認する。

## 11. 実務ケース

### Wordファイルを受け取った

顧客から `.docx` を受け取った場合、

- Word形式のまま編集するか
- 保存先はどこか
- Google形式へ変換してよいか
- 最終提出形式は何か

を確認する。

### 共有URLが開けない

- GoogleかMicrosoftか
- 正しいアカウントか
- 権限があるか

を順番に確認する。
