# VEXUM学園 ITリテラシー基礎講座

業務で必要となる基本的なIT操作とAI活用を、初学者向けに整理した社内セミナー資料です。

## 収録資料

- `VEXUM学園_ITリテラシー基礎講座_社内研修版.pptx`：編集可能なPowerPoint版
- `VEXUM学園_ITリテラシー基礎講座_社内研修版.pdf`：閲覧・配布用PDF版
- `VEXUM学園_ITリテラシー基礎講座_社内研修版_ページ別要件定義.md`：既存版のページ別制作要件
- `requirements/vexum-seminar-material-requirements.md`：今後のVEXUMセミナー資料を再構築するための統合要件定義書

## 主な内容

- VEXUMの仕事と入社後のロードマップ
- PC、ファイル、クラウド、業務ツールの基礎
- LLMとAIアプリの基本
- 生成AIの使い方、言語化、AIエージェント
- AI・情報セキュリティ
- 入社後の常駐・開発・業務テーマ

## 注意事項

- 実務で使用する場合は、所属組織の情報管理規程、利用ツール、共有ルールを優先してください。
- 入社前セミナーでは専門用語と技術詳細を必要最小限にし、実装スキルは後続研修へ分離します。
